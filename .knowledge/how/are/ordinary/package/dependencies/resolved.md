Ordinary packages can supply packed DATA typedefs and constant configuration to typed Pigen declarations, including native AXI ports, storage, child modules, arrays and fabrics. Qualified uses, header/unit/block imports and transitive package imports/exports retain canonical type and constant identities. Namespace semantics: how/are/native/axi/package/types/represented.md; how/are/native/axi/package/imports/resolved.md; how/are/native/axi/package/exports/represented.md.

src/syntax.c:structured_package_at selects native packages and supported ordinary packages required by typed contexts. ordinary_package_items_supported admits typedef, parameter/localparam, import/export and ordinary inline function/task item lists. Subroutine bodies remain retained while routine names get package symbols (how/are/retained/package/subroutines/represented.md); scoped body uses can activate package imports/exports (how/are/retained/package/namespace/uses/resolved.md). Enum/class/union typedefs, package variables and other items remain outside this ordinary companion path. Existing native package validation applies to packages with native protocol syntax.

ordinary_package_needed scans typed modules, standalone fabrics, packages and compilation-unit references/imports, following dependencies transitively. package_context_is_typed recognizes native contracts, native-type namespace declarations, numerical/storage/flow constructs and handshake/introspection calls. Inside ordinary packages it skips complete subroutine bodies, except decisive Pigen numerical/native constructs; handshake-looking ordinary function names do not make the package typed. A parameter named fifo does not demand a package. Traversal is bounded at 64. DATA/configuration packages register before dependent native packages or compilation-unit typedefs. Unrelated ordinary packages stay opaque.

structured_package_name identifies a parsed semantic package; IMPORT/EXPORT payload is_structured marks semantic ownership. native_import_at separately tests native protocol-type facts. Ordinary-only imports therefore do not force preserved procedures into structured process grammar. Native type imports still select lowering when erased declarations require it.

parse_structured_package reuses type/parameter owners. Package constants create no hardware module; packed records retain schema/state/signedness. No textual substitutions supply DATA types or configuration values. output.c renders ordinary declarations and retains subroutine bodies and unrelated SV items.

Evidence: ordinary_package_tests in tests/native_protocol_test.py checks seven independent value simulations with fatal Verilator lint and Icarus: qualified/header/block lookup, transitive exports, ordinary typedef ports, preserved function-using procedures, an unrelated function package and an unused configuration with a parameter named fifo. A buffered helper scores 64 stalled transfers. Three rejection cases preserve output for missing DATA types, duplicate constants and required class-containing packages. ordinary_package_source supplies standard packed ranges/records and address/ID/storage constants to 30 all-family standard-pin profiles, including parameterized children; native_array_test.py covers direct/child/standalone fabrics and generated type keys. Mixed-subroutine profiles have their own evidence owner. examples/native_axi_packages.pigen uses data_configuration as shared DATA/configuration.

Remaining: packages mixing eligible declarations with classes, DPI/extern/prototypes, package variables, enums/unions or other retained items; typed function evaluation; richer retained-body namespaces and opaque-import export discovery. Such ordinary packages can be preserved but cannot yet supply complete structured semantics. Broader ordinary-package integration remains incomplete. Native module-interface/fabric acceptance is tracked separately in what/is/the/native/axi/acceptance/status.md.
