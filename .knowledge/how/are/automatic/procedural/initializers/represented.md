Selected typed always_comb blocks accept explicit automatic variable declarations, with or without initializers. Every block entry initializes fresh storage: two-state packed integral types default to zero and four-state types to X, including packed records as whole vectors. Fixed unpacked arrays default each element. Explicit initializers then execute in declarator order using assignment context, so dependent comma declarators and current loop indices work. Unqualified declarations retain static lifetime; initialization still requires an explicit static or automatic qualifier.

IEEE 1800-2017 §§6.8, 6.21 and 7.2.1 supply these rules ([standard](https://fpga.mit.edu/6205/_static/F25/documentation/1800-2017.pdf)). Hierarchical names cannot access automatic variables. Static startup initializers cannot capture automatic variables, including through peek. Normal lexical lookup, declaration order, buffered-read/peek requirements and assignment shape checks apply. Nets, endpoints, buffered storage, automatic parameters/typedefs and declaration types/bounds depending on runtime iterators reject. General automatic task/function or concurrent activation support is separate retained-context work.

syntax.h signal_declaration.is_automatic preserves lifetime independently of the transfer realization. semantic.h signals carry is_automatic and entry_value separately from static initial_value. src/resolve.c resolves entry_value after binding the declarator, using pigen_resolve_shaped_assignment_value; unpacked patterns and bound mapping follow how/are/unpacked/data/assignment/patterns/resolved.md. automatic_declaration_entries builds ordinary ordered blocking assignments through the shared expression/lvalue/transfer owners. Default values precede explicit values, including self-references. Array defaults use bounded fixed-coordinate assignments with normal signed coordinate literals. Rank is bounded at 128 and storage expansion obeys maximum_generated_bits.

Private terminal variables are hoisted, with additional default drives at process entry to keep inactive automatic temporaries fully driven under fatal latch lint. Lexical block-entry assignments still run on every entry; initializer expressions are never moved to the prologue. Hierarchical escape and static capture rejection make out-of-scope terminal values unobservable. Native collection foreach bypasses the static declaration cache for automatic variables, resolving each specialized lane's initializer with its own coordinate bindings. Static declarations retain canonical aliases (how/are/native/axi/collection/foreach/loops/resolved.md).

Evidence: tests/automatic_local_initializer_test.py compares 1,024 changing/X/Z inputs against native automatic-function activations, covering defaults, dependent snapshots, mixed packed records, unpacked arrays, loop entry/continue and output-preserving lifetime negatives. Icarus cannot override variable lifetime in a static process, so independent automatic function calls provide each oracle activation. tests/native_foreach_test.py automatic profiles independently score all three AXI families across six buffered lanes and 128 reset epochs, including iterator-dependent initializers and retained peek snapshots. Static startup initialization remains owned by how/are/static/procedural/initializers/represented.md.
