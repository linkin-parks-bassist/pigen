The semantic model owns separate canonical protocol-type, scalar endpoint and endpoint-array arenas. include/pigen/ids.h defines their distinct IDs; include/pigen/semantic.h declares records/APIs and src/semantic.c owns storage and lifetime. Array collection identity and source integration are owned by how/are/native/axi/endpoint/arrays/represented.md.

pigen_protocol_type_intern validates and interns the complete pigen_protocol contract independently of role and storage. pigen_semantic_protocol_endpoint binds a PIGEN_SYMBOL_PROTOCOL_ENDPOINT symbol to its module, protocol type, role, port/internal flag and independent channel signal IDs. An endpoint is not a scalar signal or scalar data type.

pigen_protocol_endpoint_add validates symbol/module ownership, introducing syntax/span, role/port form, precisely the required channels, matching concrete payload widths, scalar channel shapes and role-derived port directions. The low-level arena can represent internal channel direction, but production declarations permit only module/fabric input/output ports. Fabric and child bindings require fixed boundary roles (how/are/internal/native/axi/child/bindings/resolved.md). buf/skid/fifo storage retains protocol identity independently of realization; static and pulse storage reject. Payload-free streams use a one-bit handshake carrier without payload fields. Missing/unexpected/repeated channels and channels owned by another endpoint reject before binding. Accessors preserve symbol/object identity; pigen_protocol_endpoint_for_signal retrieves channel ownership.

Parser, resolver, channel/field expressions, transfer checking and standard-pin lowering consume these records. Complete channel copies validate contracts; scalar/partial-field copies require full-record construction. Channel aliases expose named typed fields through ordinary struct-member resolution. Named patterns construct complete target-schema records (how/to/construct/typed/records.md). Private RTL names derive from endpoint/channel identities as endpoint__pigen_channel_aw, or beat for Stream; instance proxies retain separate mappings.

Native input channels own receive storage; external handshakes inject complete records while Pigen consumes internal tokens. READY follows registered capacity; buf accepts only while empty. Native port lowering isolates external interfaces. src/fabric_lower.c native_fabric_channel reads payload/valid/source_ready and writes input_payload/input_valid/input_ready, preserving parent storage. Fabric-owned channels suppress unused-ready defaults. Rising-edge clock/reset bindings validate controls and pre-bind channel domains before storage lowering.

Instance views retain instance and child endpoint IDs, reverse the child role and own storage-free parent channel proxies. Construction validates channel-to-instance mappings and rejects duplicate views. pigen_instance_protocol_endpoint retrieves the aggregate. Child controls translate into checked parent bindings before aggregate transfers. resolve.c:connect_protocol_aggregate checks canonical protocol identity, then applies ordinary assignment conversion per channel; packed DATA matching for collection type keys is separate. Named/positional connections and forward sibling projections use normal transfer ownership. Native fabric edges retain introducing syntax/module, endpoint IDs, direct/routed form and provenance; how/are/native/axi/fabrics/connected/and/arbitrated.md owns routing validation/lowering.

Evidence: make protocol-semantic-test exercises all families, both roles, low-level internal/port forms (production rejects internal declarations), buf/skid storage, canonical identities, invalid widths/directions/storage/channels and duplicate ownership, plus checked multidimensional collections. Contract layouts are owned by how/are/native/axi/protocol/contracts/represented.md.
