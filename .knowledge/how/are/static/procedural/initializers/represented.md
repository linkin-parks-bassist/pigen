Selected structured always_comb blocks accept explicit `static` declaration initializers for procedural variables, including comma declarators, Pigen numerical types and packed records. Initialization occurs once before simulation processes, regardless of whether the declaring branch is entered. It adds no executable assignment to the combinational body. An initializer requires explicit static or automatic lifetime; per-entry initialization has its own owner (how/are/automatic/procedural/initializers/represented.md). IEEE SystemVerilog section 6.21 requires explicit static intent in these procedural declarations ([primary specification](https://fpga.mit.edu/6205/_static/F25/documentation/1800-2017.pdf)).

include/pigen/syntax.h stores has_initializer/initializer on each signal declarator. src/syntax.c parses the expression within the declarator's bounded extent, preserving nested expression/record commas; for-header name-only probes do not consume their separately owned per-entry assignments. parse_combinational_declaration enforces explicit lifetime and existing variable/net/storage restrictions. Source scopes and declaration order are owned by how/are/combinational/block/local/declarations/represented.md.

src/resolve.c resolves the initializer after declaring its variable, using pigen_resolve_shaped_assignment_value against the declared type and shape. Existing assignment conversions, fill sizing and record schemas apply. Unpeeked buffered reads reject because startup initialization cannot consume tokens. Automatic locals and procedural for/foreach iteration values cannot be captured, including through peek; native foreach iterator checks preserve lexical shadowing. Runtime expressions over static signals are captured at startup, rather than treated as elaboration constants. Fixed unpacked patterns and ordinal bound mapping follow how/are/unpacked/data/assignment/patterns/resolved.md.

semantic.h adds initial_value to pigen_semantic_signal; pigen_signal_add initializes it invalid. A valid initializer is metadata on that static signal. Existing native foreach declaration aliases share the same signal and initializer across specializations. RTL lowering waits until declarations and native endpoint views exist, lowers the expression through lower_expr and attaches it to the payload VARIABLE object's existing initial_value field. sv_emit.c validates initialized objects as internal variables/parameters and emits a declaration assignment. Parameter initialization retains its existing route; ports cannot receive these initializers.

Evidence: tests/static_local_initializer_test.py compares 1,024 changing inputs with native SV, including startup input snapshots, an initially disabled branch, packed record literals, fills, dependent comma initializers and reg variables. Three parameterized native child profiles verify independent 32/64-bit captures. Negatives preserve output for implicit initializer lifetime, unknown names, malformed expressions, buffered reads, nets and iteration-variable captures. tests/native_array_test.py generate_static_init profiles exercise generated packed-record/numerical initializers and native `$bits` references through all three AXI families, with independent standard-pin stalls/reset scoreboards.
