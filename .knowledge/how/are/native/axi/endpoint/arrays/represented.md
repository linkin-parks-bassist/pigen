Native AXI array declarations use ordinary declarator dimensions, for example `input uint[32] axi4_stream fifo[3] s[-2:-1][2]`. Each coordinate selects an independent AXI endpoint, including its channel handshake and storage state. `s[-2][1].data` selects a Stream field; `bus[0].aw` selects a memory-mapped channel. Scalar endpoint indices must be constant, in bounds and cover every dimension. Scalar/collection coordinate rules and remaining limits: how/are/native/axi/collection/selections/resolved.md. Collection views support partial indices and slices (how/are/native/axi/collection/selections/resolved.md). Runtime payload-field indexing remains a separate operation.

include/pigen/semantic.h and src/semantic.c own pigen_protocol_array_id and PIGEN_SYMBOL_PROTOCOL_ARRAY. Collections bind a module, canonical protocol type, role, port/internal flag and shape to ordered scalar endpoint IDs. COUNT dimensions mean descending [N-1:0]; explicit ranges retain signed bounds and direction. pigen_protocol_array_shape_size validates cardinality before declaration expansion. pigen_protocol_array_add caches evaluated bounds, rejects invalid/unresolved/zero/overflow dimensions, mismatched lane counts, inconsistent lexical scope/module/type/role/port flags, duplicate lanes and lanes owned by another collection. Failed validation does not publish the collection. pigen_protocol_array_element performs read-only rank/bounds checking in row-major declaration order. Reverse lookup returns collection and ordinal. pigen_protocol_arrays_can_connect requires complete compatible contracts, complementary roles and matching rank/dimension cardinalities.

src/resolve.c expands declarations into scalar lanes before normal clock/reset binding. src/expression_analysis.c resolves indexed/qualified references through collection/instance identities (how/are/named/generate/scope/paths/resolved.md). `child.bus[i]` selects the existing storage-free scalar instance view. Whole/selected-array child bindings map declaration order when rank/cardinalities match, including different bounds/directions. Assignment-like concatenations construct child collections from scalar endpoints, rows and existing collections (how/are/native/axi/collection/concatenations/resolved.md). Positional patterns construct one element per entry; nested, index/type/default and replicated patterns preserve the same endpoint identities (how/are/native/axi/collection/assignment/patterns/resolved.md). Every lane retains complete-contract, role, timing and ownership validation. Positional port enumeration counts a collection once and excludes its generated lanes.

src/rtl_lower.c emits standard flattened channel pins with coordinate suffixes: s[-2][1] has s_m2_1_tdata/tvalid/tready; negative coordinates use m followed by magnitude. Internal lane names derive from semantic IDs independently of the public pin names. Dimension order and direction remain meaningful. Declaration lane count is bounded by the compiler's generated-size policy.

Native whole-interface fabric links, including indexed and whole-collection links, are quarantined and not in use (how/are/whole/axi/array/fabric/connections/resolved.md). Endpoint arrays and child bindings remain active.

Evidence: make protocol-semantic-test covers all families, both roles and arena forms; source declarations are boundary-only and buf/skid collection invariants. The retained pre-quarantine tests/native_array_test.py independently scores multidimensional lanes across all families/fields under stalls/reset through direct transfers, scalar child bindings, indexed child projections, whole/selected-array named/positional connections, rebased ports, forward sibling arrays, parameter overrides and indexed/collection fabrics across parent, child, generated and standalone boundaries. Generated process, child-boundary and fabric cases also cover nested signed-coordinate loops, local parameters and branch selection. Negative witnesses cover nonconstant/out-of-range indices, incomplete rank, invalid counts, shapes, contracts, roles, ordinary token arrays and duplicate consumers. These are transport witnesses rather than full legal burst-sequence coverage. Scalar identities: how/are/semantic/axi/endpoint/identities/represented.md.
