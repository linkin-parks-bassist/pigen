include/pigen/protocol.h and src/protocol.c own backend-neutral protocol contracts for AXI4-Stream, AXI4-Lite and AXI4. A pigen_protocol carries family, data/address/ID/destination widths, per-channel USER widths and selected stream KEEP/STRB/LAST fields. Protocol identity is separate from endpoint role and storage realization. No AXI3 WID is represented.

pigen_protocol_layout derives ordered field identities, bit offsets and total payload width for one independent channel. AXI4-Stream has BEAT; memory-mapped families have AW/W/B/AR/R. AW/W/AR and BEAT flow from initiator; B/R flow from target. Full AXI4 includes burst, lock, cache, protection, QoS and region fields plus independently sized optional USER fields. AXI4-Lite includes protection, write strobes and response fields. Stream data is byte-sized and may be omitted; KEEP/STRB require data. Full data widths are powers of two from 8 to 1024; Lite is 32 or 64. Zero ID/USER/destination width denotes omission where applicable. Invalid family-specific configuration and channel-layout overflow fail closed.

pigen_protocol_equal compares complete validated contracts without struct-padding assumptions. pigen_protocol_can_connect additionally requires complementary valid roles. Equal payload width alone never establishes compatibility. Adaptation requires an explicit operation with defined behavior. Semantic protocol types and endpoints consume this contract (how/are/semantic/axi/endpoint/identities/represented.md). Source declarations, typed channels/fields, transfers and standard pin lowering are implemented (how/to/write/native/axi/declarations.md). Receiver boundaries use capacity-isolated channel storage. Clock/reset bindings are separate endpoint identities (how/are/native/axi/clock/domains/bound.md). Child aggregates and translated cross-instance bindings use these identities and pass stalled hierarchy simulations. Native single-source fabric links and packet-preserving stream merges consume complete contracts (how/are/native/axi/fabrics/connected/and/arbitrated.md). Memory-mapped groups preserve AW/W ownership and B/R routes through completion; pigen_protocol_can_route defines AXI4 and Stream ID widening/source tags while keeping other fields exact. Switched Stream merges require provenance space and exact-ID packet tracking is storage-bounded in the completed graph (how/are/native/stream/fabric/identities/preserved.md); exclusive monitor witnesses cover colliding/absent IDs; passing contract-owner tests alone is not end-to-end AXI support.

Provisional void axi4_stream declarations expose omitted DATA in source, including metadata and handshake-only beats. Storage, child/collection bindings, arbitration, switching and source syntax evidence are owned by how/to/write/axi/streams/without/data.md. Zero integer counts remain invalid.

make protocol-test checks every full-AXI data width, Lite widths, independent USER and ID layouts, all stream sideband combinations, omitted data, channel roles, compatibility rejection, invalid configuration and overflow. AddressSanitizer/UndefinedBehaviorSanitizer also pass for this test. These checks verify the contract owner rather than protocol timing or fabric behavior.

Protocol evidence: Arm IHI 0022F.b, https://documentation-service.arm.com/static/5f915bbcf86e16515cdc3b23 (AXI4 sections), and IHI 0051A, https://documentation-service.arm.com/static/642583d7314e245d086bc8c9. Native feature requirements: what/are/the/native/axi/transfer/requirements.md.
