Inline fabrics accept native parent ports and child endpoints: `fabric begin s -> m; endfabric`. Matching native arrays expand into scalar links, including indexed named generate paths (how/are/native/axi/endpoint/arrays/represented.md; how/are/named/generate/scope/paths/resolved.md). `>` selects exclusive direct wiring. All three families preserve channels/sidebands, reversing memory-mapped B/R. Routed unannotated single-source links add a two-entry skid per channel; native boundary storage remains active. Typed standalone fabrics reuse these contracts (how/to/write/typed/standalone/fabrics.md).

AXI4 routed groups prefix AWID/ARID with stable source indices and strip those prefixes from BID/RID. Target IDs need at least source ID width plus ceil(log2(source count)); insufficient space diagnoses. Initiators share one source contract; other fields match exactly. pigen_protocol_can_route owns this law. Ordinary child bindings/channel copies require exact contracts. Single-source widening zero-extends IDs; omitted source IDs still receive target tags. Repacking uses canonical fields/offsets. examples/native_axi_relay.pigen contains native_axi4_merge2 and native_axi4_switch2x2.

The resolver publishes pigen_semantic_protocol_fabric_edge syntax/module/source/destination identities, direct/routed form, optional evaluated address windows and provenance. Ports and child views keep fixed role directions. Internal native declarations are forbidden; intermediate protocol storage requires an explicit child module boundary. Clock/reset and complete contract checks remain active. Self-links, invalid source reuse, shared direct destinations and competing local/child transfers reject; peek is non-consuming. Native edges lower before ordinary scalar edges. Boundary-only declaration and child-view laws: how/are/internal/native/axi/endpoints/connected/through/fabrics.md.

Stream groups use pigen_axis_merge with two receive slots per source. Switched groups arbitrate per beat; exact-ID grants wait for every open stream packet to close. TDEST selects source-local destinations, with TID widening preserving provenance (how/does/the/native/axi/stream/destination/switch/work.md; how/are/native/stream/fabric/identities/preserved.md).

AXI4-Lite/full sources switch through inclusive `at [BASE:LIMIT]` windows and pigen_axi_demux. Five virtual channel endpoints per edge compose decoding with target arbitration; unmapped requests receive DECERR. how/does/native/memory/mapped/address/routing/work.md owns scope, bounds, transaction state and independent standard-pin witnesses.

Memory-mapped fan-in uses pigen_axi_merge: one outstanding write and an independent read per target. Round-robin ownership accepts W before AW, holds AW/W association through B, and reads through RLAST (one beat for Lite). Effective bindings include active-low synchronous reset. RTL parameters carry widths and LAST offsets; emission performs no inference. pigen_rtl_primitive_port_is_output prevents default zero drivers on primitive outputs.
