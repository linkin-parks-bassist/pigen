Native typedefs provisionally name a complete payload/protocol contract: `typedef bit[32] axi4_lite[addr=40] reg_bus_t; typedef reg_bus_t copied_t;`. Use `input copied_t fifo[2] s;`. Direction determines role; storage and timing belong to each endpoint use. Uses can add `[clock=ACLK,resetn=ARESETn]` but cannot replace fields. Alias definitions reject timing options.

include/pigen/syntax.h stores a protocol occurrence on type_definition. src/syntax.c records typedef family for endpoint classification. PIGEN_SYMBOL_PROTOCOL_TYPE in semantic.h retains payload data_type and canonical protocol_type. semantic.c:pigen_symbol_bind_protocol_type checks kind, payload width, valid contract and consistent rebinding; pigen_symbol_protocol_type follows canonical symbols. resolve.c:add_typedef resolves explicit contracts/alias chains; add_protocol_declaration reuses contracts with per-use storage/bindings. Native aliases are not packed data types.

specialize.c:native_type_hints classifies source-order typedef uses with lexical scopes and ordinary typedef shadows. Module/port/process classification recognizes aliases; parameterized native children defer to semantic specialization. Hints never supply contracts. Forward source-order diagnostics cover native header/declaration/query/cast forms (how/are/native/axi/forward/typedef/references/diagnosed.md); broader retained-SV/value shadowing needs auditing. Simple named native type keys use complete contracts and packed DATA matching in child collection patterns (how/are/native/axi/collection/assignment/patterns/resolved.md).

Root `$bits(bus_t)` and `bus_t'(32'd1)` assignments select structured resolution and reject before emission. expression_analysis.c:inquiry_type rejects native type arguments; resolve.c preserves underlying diagnostics. protocol_alias_at respects parsed parameter/value/typedef shadows. retained_declaration_shadows parses retained wire/tri/reg and builtin variable type prefixes in temporary expression/type arenas, then scans only declarator names. Typed and implicit nets, grouped names and nested initializers preserve lexical value shadows; initializer references introduce no barriers. Broader retained grammar remains work. IEEE 1800-2017 §6.18 requires typedef declarations before use and forbids hierarchical typedef references ([standard](https://fpga.mit.edu/6205/_static/F25/documentation/1800-2017.pdf)); forward diagnostics and their remaining scope are owned by how/are/native/axi/forward/typedef/references/diagnosed.md.

Compilation-unit, module-local and qualified package aliases are supported (how/are/native/axi/package/types/represented.md). Module-local contracts can reference module parameters, and alias chains retain those resolved contracts under child overrides. syntax.c:parse_module_body omits retained source ranges for recognized native typedefs; ordinary SV typedef retention remains intact. examples/native_axi_named_types.pigen demonstrates a global Stream alias, local Lite/full aliases, alias chains and parameterized ADDRESS_BITS/ID_BITS. The examples use whole-bus internal fabric transit; the full-AXI example is a typed standalone fabric with local aliases/storage. parse_fabric_block reuses declaration parsing in that owning module scope.

Evidence: tests/native_protocol_test.py independently scores standard pins for all families, direct/child/fabric connections, global/local alias chains, timing, storage and parameterized children under stalls/reset. named_type_example_tests fatally lints default examples and child overrides with 24/48-bit addresses and 2/6-bit AXI4 IDs. Negatives preserve output for field overrides, typedef timing, protocol stacking, storage/fabric incompatibility and packed queries/casts. Shadow tests simulate parameters, typed/grouped/implicit/signed nets, integer variables and packed typedefs. Negative cases preserve output when an initializer merely mentions the AXI type. tests/native_array_test.py checks compilation-unit aliases through nested parameterized children, generated collection fabrics and keyed bindings for all families. tests/specialization_test.c checks native deferral and ordinary typedef shadows. These witnesses do not establish full seamless AXI support.
