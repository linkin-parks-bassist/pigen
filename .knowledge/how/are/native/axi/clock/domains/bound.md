Native AXI endpoints own a validated clock/reset binding separately from the protocol's field contract. Use clock=ACLK with reset=RST for active-high reset or resetn=ARESETn for active-low reset. Omitted bindings select module inputs clk and reset. Clock and reset must each resolve to a scalar static module input; reset/resetn are mutually exclusive. Reset is sampled synchronously by the channel storage, with active-low input normalized at RTL lowering.

The resolver binds after collecting module declarations, so control inputs may appear after endpoint declarations. It resolves control expressions to symbol identities and interns the rising-edge domain. pigen_protocol_endpoint_bind in semantic.c validates controls, role-independent ownership and compatible channel domains, then binds every channel to that domain. Binding is idempotent only for the same clock/reset/polarity. The endpoint constructor rejects fabricated pre-bound records; bindings use this checked API.

Transfer analysis checks channel uses against the pre-bound domain. Another clock reports signal used across clock domains. Unsupported edge controls referencing native AXI endpoints diagnose at the original process instead of falling through into retained/omitted text. Retained edge-clocked payload observations also check the endpoint's bound clock identity, using the event's enclosing scope rather than body-local shadows (how/are/retained/native/axi/observations/represented.md). RTL storage_endpoints uses the endpoint's clock identity and normalized reset expression. Ordinary non-protocol storage retains its existing clk/reset convention.

The retained pre-quarantine suite verifies renamed clocks, active-high and active-low reset, control declarations after endpoints, isolated outputs and reset recovery with full queues for all three families. Eight negative witnesses cover clock/edge mismatch, missing or non-scalar controls, non-static clocks, computed clock binding and conflicting reset polarities. protocol-semantic-test verifies checked binding, idempotence and rejected rebinds across families, roles and storage forms. examples/native_axi_relay.pigen includes a standard-named ACLK/ARESETn relay.

Child aggregate views translate the child's bound controls through resolved instance connections into scalar static parent input identities. Reset connections may invert polarity with logical not. resolve.c unwraps conversion/group nodes both outside logical not and around its operand, preserving the input identity after assignment contextualization. Every channel inherits the translated domain. Aggregate bindings and direct channel copies require equal clock domains, reset symbols and effective polarity. Native hierarchy simulations cover renamed active-low controls, inverted resets and forward sibling connections for all families, with negative timing witnesses. The quarantined single-source native fabric links and stream merges used these translated identities, including active-low resets. The quarantined memory-mapped contention code also used these identities; how/are/native/axi/fabrics/connected/and/arbitrated.md owns fabric behavior. Tests establish synchronous reset behavior; asynchronous reset remains unqualified. Source owners: syntax.h/syntax.c, semantic.h/semantic.c, resolve.c and rtl_lower.c. Receiver capacity isolation is covered by what/remains/for/native/axi/boundary/isolation.md.
