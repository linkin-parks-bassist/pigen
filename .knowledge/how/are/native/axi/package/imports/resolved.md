Structured packages support explicit `import buses::bus_t;` and wildcard `import buses::*;` in compilation-unit, module-header/body, package, selected generate, typed standalone-fabric and structured procedural block scopes. Bindings retain the original package symbol, DATA schema and complete protocol contract, without new storage or copied contracts (how/are/native/axi/package/types/represented.md).

syntax.h IMPORT nodes carry package/member tokens, wildcard/is_structured flags and locations. syntax.c:parse_import handles comma-separated entries. protocol_alias_at consults preceding imports for classification; semantic resolution owns their meaning. Module-header import semicolons do not end the header. specialize.c:imported_native_hint preserves semantic specialization of imported native children.

semantic.h/semantic.c own pigen_semantic_import and pigen_import_package. Explicit imports reject local/import conflicts and allow repeated imports of the same member. Wildcards initially add candidates. pigen_symbol_lookup/lookup_text and source-position-aware lookup_at/lookup_text_at remain pure; pigen_symbol_resolve_at/resolve_text_at activate a selected wildcard name. Expanded-token positions limit value visibility and activation. Retained calls separately use completed-scope bound names with source-point candidates (how/are/retained/package/calls/bound.md). pigen_symbol_declare rejects replacement of an explicit or activated import.

Each lexical scope searches declarations, bound imports, then wildcard candidates before searching outward. Ambiguous candidates diagnose without borrowing an outer declaration. Unused candidates permit local shadows. Imports neither implicitly re-export names nor expose them through hierarchical lookup. Basis: IEEE 1800-2017 §26.3 ([standard](https://fpga.mit.edu/6205/_static/F25/documentation/1800-2017.pdf)).

resolve.c:bind_import_uses binds module/generate-scope continuous-assignment, instance and structured combinational/clocked process references before later declarations; it creates no values, reads or hardware. Builtin callee spellings skip activation unless pure lookup at that source position finds a retained subroutine; an unrelated wildcard parameter or later function import cannot alter an earlier intrinsic. Procedural syntax barriers protect local signals, parameters, typedefs, named blocks and foreach indices. For-header declarations extend across the loop rather than only its synthetic initializer block; sibling blocks do not hide outer names. output.c omits explicit native type imports, preserves wildcard/ordinary-member imports and emits explicit ordinary imports for activated names. This preserves binding when lowering removes the first use that originally froze a wildcard name.
