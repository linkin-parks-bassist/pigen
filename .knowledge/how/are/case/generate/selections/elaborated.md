Native case-generate resolves a constant selector and every constant label before selecting hardware. src/syntax.c preserves CASE, ordered CASE_ITEM and CASE_LABEL nodes with original expression spans. Comma-separated labels, ternary labels, optional default colons and null bodies are supported. Only case is a generate selector; native casez/casex generate forms diagnose. Ordinary SV regions retain their preservation path.

src/resolve.c computes one comparison width from the maximum selector/label width; comparison is signed only when every operand is signed. pigen_const_expr_case_equal in src/semantic.c compares exact 0/1/X/Z states after this extension. The first matching item wins, default is used only when no label matches, and no match without default publishes no hardware. All labels must resolve even when an earlier label matches. Only the chosen body enters the shared lexical scope, declaration, child-specialization and fabric owners.

The bit evaluator supports literals, parameters/conversions, concatenations, conditional selection and X merges, unary/reduction and bitwise operations, plus operations supported by existing numeric evaluators. Unsupported wide arithmetic fails evaluation. SV conditional alternatives preserve four-state bits, common maximum width and signedness only when both alternatives are signed (src/data_type.c). Pigen numerical alternatives retain their separate typing rules.

The comparison/selection contract follows IEEE 1800-2017 sections 12.5 and 27.5 ([IEEE text](https://fpga.mit.edu/6205/_static/F25/documentation/1800-2017.pdf)). Source block-name checking includes unselected branches (how/are/generate/block/name/conflicts/validated.md). External-name metadata is available (what/are/automatic/generate/block/names.md); owned RTL references are available (how/are/source/paths/mapped/to/rtl/names.md). Retained-SV namespace auditing and broader scoped retained-SV integration remain incomplete; see how/are/structured/generate/scopes/elaborated.md.
