Selected structured always_comb blocks support static and explicit automatic local variables, including scalar/unpacked initializers (how/are/unpacked/data/assignment/patterns/resolved.md), local typedefs, comma-separated parameter/localparam declarations and package imports (how/are/procedural/package/imports/resolved.md). Declarations precede executable statements within each block. Nested blocks can shadow enclosing variables and types; unqualified locals do not escape their lexical block. Named typed blocks provide qualified member paths (how/are/named/procedural/blocks/resolved.md). Native endpoints, ports, buffered transfer annotations and wire nets are not procedural variables and reject here. Automatic lifetime and per-entry defaults/initializers are owned by how/are/automatic/procedural/initializers/represented.md. Named-block forward elaboration and retained/clocked hierarchy remain integration work. For-header declarations and their per-entry initialization have a separate owner: how/are/combinational/for/loops/represented.md.

src/syntax.c reuses normal type/declaration owners beneath PROCEDURAL_BLOCK nodes. Declaration probes require a declarator after the type, so indexed assignments such as value[0]=0 cannot be claimed as parameterized-type declarations. Omitted transfer annotations select LOGIC independently of normal numerical omission policy, so uint[N]/int[N] locals use variable realization independently of lifetime. Bare int in this procedural syntax context resolves to the SV signed 32-bit two-state integral type; unsigned changes signedness. The public Pigen int constructor still requires its width argument. include/pigen/type_syntax.h carries the contextual flag and src/type_resolve.c resolves it.

parse_procedural_parameters splits constants only at top-level commas. An explicit type belongs to the whole declaration; untyped declarators infer their values independently. Each PARAMETER node resolves in source order, so later values can reference earlier constants. Repeated types, trailing commas, forward references and duplicate names reject. Nested expression commas remain inside their values. Source specialization excludes begin/end block constants from its module-wide localparam substitution table.

src/resolve.c creates an is_procedural lexical scope for each block, resolves declarations in source order, and restores the enclosing expression scope on return. Stable symbol identities preserve nearest lookup and nested shadowing. Static declarations contribute no executable children; automatic declarations contribute ordered entry assignments. src/rtl_lower.c gives procedural-local signals scope-qualified terminal names. src/output.c skips the complete source combinational body, including parser gaps and declaration text; typed RTL owns the emitted statements and declarations.

Hoisted private variables preserve default static lifetime: IEEE 1800-2017 §6.21 states that variables in static procedural blocks default to local scope and static lifetime ([IEEE text](https://fpga.mit.edu/6205/_static/F25/documentation/1800-2017.pdf)). Explicit static declaration initialization is stored as startup metadata, never replaced by a blocking assignment on block entry (how/are/static/procedural/initializers/represented.md). Data foreach resolves its body once; native collection foreach shares canonical static declarations across specialized branches (how/are/native/axi/collection/foreach/loops/resolved.md).
