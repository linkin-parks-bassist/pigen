Selected structured always_comb processes accept +=, -=, *=, /=, %=, &=, |=, ^=, <<=, >>=, <<<= and >>>= plus standalone prefix/postfix ++ and --. Operand families still determine admissibility: Pigen numerical division/remainder remain fail-closed (is/pigen/division/specified.md). Updates are ordered blocking statements; the ignored value of a standalone prefix/postfix update does not require expression-side effects. Updates embedded inside expressions remain unsupported.

src/syntax.c shares compound_assignment_operator with generate-loop parsing. A BLOCKING_ASSIGNMENT retains its destination/value expressions, compound flag/operator and signed increment flag; increments have an invalid RHS identity. Only a top-level compound token splits lvalue and RHS, so nested selections/grouping retain their expression structure. Plain = parsing remains separate.

src/resolve.c resolves the destination once, then resolve_static_update reuses that semantic expression as the read operand. The data-type owner resolves the binary operation and operand conversions. The computed result receives an explicit conversion back to the original variable type, which permits unsigned numerical decrement and wrap after lossless subtraction; ordinary = keeps its separate assignment-conversion policy. Generated left-shift widths obey the configured width limit and carry symbolic constraints. The resulting static transfer records every written lvalue leaf and the read/index dependencies, without acquiring buffered consumers or producers. Buffered destinations, unpeeked buffered reads, read-only targets, whole unpacked-array arithmetic and side-effecting indices reject.

Supported index expressions are pure. Reusing their semantic identity and emitting an ordinary blocking assignment is observationally equivalent to evaluating a compound lvalue index once. This is not a license to duplicate effectful calls when those contexts gain support. IEEE 1800-2017 §§11.4.1–11.4.2 define the blocking behavior and index rule ([IEEE text](https://fpga.mit.edu/6205/_static/F25/documentation/1800-2017.pdf)).

Semantic/RTL statement trees remain ASSIGN nodes with typed values; no raw-body rewriting or terminal-emitter operator discovery is involved. tests/generate_semantic_test.c checks read/write incidence on the same local symbol. tests/cores/continuous_intrinsics* compare all twelve operators, both increment forms, mixed widths/signs, X/Z, runtime zero divisors, concatenated targets, numerical wrap and changing runtime indices against native SV references. The wider-divisor oracle exception is owned by why/does/icarus/compound/division/disagree/with/systemverilog.md. tests/native_array_test.py exercises updates in explicit/implicit generated scopes and child-input wiring for all AXI families under stalls/reset, with output-preserving negative witnesses. examples/native_axi_generated.pigen uses a compound update on block-local handshake flags. Ordered execution is owned by how/are/scoped/combinational/processes/represented.md.
