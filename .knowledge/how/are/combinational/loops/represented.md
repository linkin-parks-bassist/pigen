Selected typed always_comb processes support for, while, repeat, do/while and forever with ordered blocking bodies, nested scopes and lexical loop exits. While tests before each iteration; do/while executes the body before testing, including after continue. Repeat evaluates its count once. Forever repeats until control leaves it. Break exits the nearest loop; continue reaches the next iteration, including FOR's ordered steps. Ordinary retained SV keeps its preservation path.

include/pigen/syntax.h declares procedural loop kinds and procedural_loop.control. WHILE/REPEAT parse parenthesized leading controls. DO_WHILE parses its body followed by while(control) and a required semicolon; FOREVER has a body without control. Extent discovery skips complete bodies so their intrinsics select typed lowering. Nesting uses the existing 128-level bound. For headers have a separate three-phase model and loop scope (how/are/combinational/for/loops/represented.md). Fixed-array/packed-field foreach lowers to one ordinal FOR, preserving multidimensional exits and static locals (how/are/combinational/foreach/loops/represented.md).

src/resolve.c uses pigen_resolve_control_expression for scalar integral or exact-integer controls and rejects consuming buffered observations without peek. Native signedness/context, truth normalization and repeat count sizing are owned by how/are/combinational/controls/resolved.md. Ordinary body declarations default to static lifetime. Explicit automatic locals default and initialize on every body entry (how/are/automatic/procedural/initializers/represented.md).

Semantic and RTL WHILE/REPEAT/DO_WHILE nodes carry control and exactly one body child. FOREVER has one body child and no condition. Constructors enforce control/arity and ownership before publication. FOR retains distinct initializer/step/body phases. rtl_lower.c preserves these trees. sv_emit.c renders loop bodies within private lexical exit/iteration blocks, using while-based FOR emission for Icarus compatibility; how/are/combinational/loop/exits/represented.md owns target validation and rendering. Driver queries recurse through all phases, including concatenated child-port writes.

Evidence: tests/generate_semantic_test.c checks kinds, controls and publication; tests/rtl_test.c checks invalid controls/arity, orphan exits and driver queries; tests/sv_emit_test.c checks malformed-tree rejection before output. tests/cores/continuous_intrinsics* compares counts, mutation, signed controls, nested shadowing, case exits and four-state conditions with independent scoreboards. A separate warnings-fatal Verilator profile compares authored native break/continue loops with emitted RTL over all 256 input bytes. tests/native_array_test.py generate_comb/implicit/child exercises every loop form for all AXI families under stalls/reset and checks malformed/buffered-control negatives. Unknown unsigned repeat-count oracle limits belong to why/does/icarus/repeat/with/an/unknown/count/fail/to/finish.md. These witnesses do not establish termination or synthesis suitability of arbitrary authored loops.
