PIGEN_EXPR_EVALUATED_VALUE carries a normal integral scalar value, an evaluated operand that contributes no result bits, and a before flag preserving their authored order. Its type and shape equal the value operand's. pigen_expr_add_evaluated_value in semantic.h/semantic.c validates both operands, scalar integral types and the boolean flag; it never publishes a constant recipe, even when both operands are constant, and never supplies an lvalue. This avoids a zero-width type or artificial result bit.

expression_analysis.h owns pigen_analyzed_expr_form: ordinary records use PIGEN_ANALYZED_INTRINSIC; retained evaluations use PIGEN_ANALYZED_EVALUATED_VALUE and the evaluation union instead of the syntax-kind payload. The latter preserves typed value/evaluated child IDs and before placement without a constant recipe. Its syntax kind remains provenance, not a new parsed construct. Pure analysis publishes no semantic records; the postorder materializer builds the semantic evaluated value. Constant-context evaluation refuses this form rather than reading an unrelated union member.

expression_use.c visits both operands as reads, so an ignored buffered source still joins validity/readiness and consumes its token with the enclosing atomic transfer. Existing source deduplication prevents repeated ignored reads from consuming additional tokens. peek remains an observation and contributes no consuming use. Buffered ignored operands in always_comb still require peek. resolve.c follows both operands for symbol references and input-alias rebuilding; rtl_lower.c follows both for references, computed projections and procedural-local detection.

lower_expr preserves the record as PIGEN_RTL_EXPR_EVALUATED_VALUE, with child 0 supplying the value, child 1 the evaluated operand, and matching output type. rtl.h/rtl.c own its constructor. It validates references, matching value type, boolean placement and usable concrete/symbolic widths. sv_emit.c validates final arity/type/placement before publication and renders a native concatenation containing one zero-count replication before or after the normal value. Signed result types receive the corresponding signed interpretation. Normal values always contribute bits, making the emitted empty field legal. Concrete-width operands receive explicit intrinsic-width casts before concatenation; semantic integer literals otherwise render unsized and fail warnings-fatal Verilator lint.

Clocked cases retain otherwise ignored selector dependencies through this representation (how/are/clocked/case/statements/represented.md). Runtime packed replication and runtime rank-zero array queries also use this owner (how/are/packed/replications/analyzed.md; how/are/fixed/array/inquiries/resolved.md). Existing user-function/effect restrictions remain; the representation must not be treated as evidence that typed impure calls are implemented.

Evidence: tests/expression_use_test.c checks retained read summaries, non-lvalue behavior, invalid construction and no constant-folding even for constant operands. tests/sv_emit_test.c checks both placements and no-partial-output rejection of malformed arity/flags/type. tests/runtime_zero_replication_test.py scores ordered local reads with ignored X/Z operands, direct/child-bound independent consuming streams, duplicate ignored reads, peek and failure/output preservation. Native record and pipeline witnesses are specified by the packed-replication owner.
