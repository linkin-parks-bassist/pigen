include/pigen/syntax.h and src/syntax.c represent structured generate syntax with GENERATE_REGION/BLOCK/IF/FOR/CASE/CASE_ITEM/CASE_LABEL nodes, original locations and parent/child/sibling IDs. Templates remain intact; selection and iteration scopes belong to how/are/structured/generate/scopes/elaborated.md.

Explicit regions become structured when they contain native declarations/references, buffered references, native child interfaces or Pigen constructs, including validity/reset actions. Numerical declarations and casts select structured parsing for uint/int/bit counts. Bounded recognition distinguishes declarations/casts from ordinary SV packed bit ranges, indexed values and member names; the same policy selects numerical always_comb bodies. tests/numerical_generate_test.py checks 12 native-SV profiles with X/Z, 8/12-bit overrides and negatives. Native-child discovery scans expanded module and typed fabric definitions, including forward definitions and omitted data ports. Dynamic-name lookup walks lexical syntax ancestors and honours nearer signal declarations, including static shadows.

Implicit module-level if/for/case/named begin blocks use the same classification. implicit_generate_extent bounds complete items, including nested controls, unbraced/else bodies, end labels, clocked bodies and fabric boundaries. retained_procedural_end uses complete statement extent, including if/else and foreach, so unbraced generated clocked bodies retain their full contents. Speculative clocked parsing restores its diagnostic checkpoint on fallback; a remaining committed diagnostic stops parsing rather than being replaced by a generic event-control error. Native/Pigen items receive a GENERATE_REGION wrapper spanning exactly that item. Ordinary SV controls retain complete spans. Incomplete native controls fail rather than falling back. Case selectors retain ordered item/label expressions and default metadata; comma lists and ternary labels preserve original spans. Null bodies create empty blocks. Native casez/casex generate forms diagnose. External genblk metadata is lexical (what/are/automatic/generate/block/names.md); selection belongs to how/are/case/generate/selections/elaborated.md.

Regions/blocks own ordered module items; blocks may be named. Conditionals retain condition/else presence and both bodies. Loops retain iterator, inline-genvar flag, initial/condition expressions and update. Updates accept assignment, prefix/postfix increment/decrement and compound arithmetic/shift/bitwise assignment to the same iterator. Begin/end labels must match. Nested explicit regions reject; structured nesting is bounded at 128 levels.

Bodies use normal declaration/transfer/child/fabric/control owners. Selected always_comb bodies parse static locals, ordered blocking assignments/updates, blocks, if/else, case/casez/casex, typed loops, fixed-array/packed-field/native-collection foreach and lexical exits (how/are/scoped/combinational/processes/represented.md). Every assign in a structured body becomes typed CONTINUOUS_ASSIGNMENT nodes, one per top-level comma binding, retaining the complete statement location and individual expression spans. Empty/incomplete/trailing-comma bindings fail. Nested expression commas do not split bindings. Module-root ordinary assigns retain their separate classification (does/a/continuous/assignment/lower/handshake/intrinsics.md). Separate genvar lists publish GENVAR name nodes. Fabric/pipeline terminators participate in block matching; single-item bodies become anonymous blocks.

Parameterized children retain module/name tokens, has_parameters (including empty #()) and ordered PARAMETER_CONNECTION children with optional labels and expression identities separately from data CONNECTION children. Parsing ignores nested expression commas. Deferred root native instances share this form. Typed specialization belongs to how/are/generated/child/parameters/specialized.md. Unselected branches publish no children.

Parsing never selects branches, expands iterations or allocates semantic lanes. Selected unsupported items diagnose.
