`$bits(expression)` and `$bits(data_type)` resolve through `analyze_bits` in src/expression_analysis.c. The result is a fixed 32-bit signed four-state SystemVerilog integer constant, built with pigen_data_type_sv_integer. Its value is packed width multiplied by every fixed unpacked dimension. Counts must be positive and concrete; ranges accept ascending or descending signed bounds. Checked unsigned arithmetic rejects unresolved or overflowing total sizes. The returned 32-bit bit pattern follows the integer result width.

The argument is unevaluated: temporary analysis may intern types/constants but publishes no semantic expressions, expression children or width constraints. Materialization publishes only the constant result. Mutable signals and native channel fields are valid type sources without consumption or validity dependencies. Expression operands use the CASE literal domain, so `$bits(1)` is 32 and `$bits('1)` is 1; explicit Pigen numerical casts preserve their existing arithmetic policy. Runtime indices can determine an element type without evaluating their values.

The shared inquiry_type helper resolves the operand type and rejects PIGEN_SYMBOL_PROTOCOL_TYPE: a native endpoint alias has no packed data representation. Root alias inquiries select structured diagnostics; parameter, retained net and packed typedef shadows retain their own meaning (how/are/native/axi/type/aliases/represented.md). CALL syntax retains type_argument_kind and type_argument in include/pigen/expression.h. src/expression.c recognizes primitive and anonymous packed-struct type arguments. A suffix such as T[2] retains both a type candidate and ordinary expression syntax; lexical typedef lookup decides which interpretation applies. A variable shadowing a typedef keeps ordinary expression interpretation. Explicit signedness is a type-only form. Bare int denotes the SV 32-bit type; int[n] retains Pigen numerical spelling. Failed expression parsing restores expression nodes/children and type nodes/arguments/members, including anonymous struct members.

Native field/channel type resolution uses existing endpoint semantics: Stream values denote their complete beat payload; memory-mapped buses require a channel selection. This inquiry does not introduce a packed representation for a whole memory bus, endpoint collections or arbitrary functions. peek/valid/ready/accepts operands use typed call analysis without runtime dependencies when discarded by the inquiry (how/are/handshake/calls/analyzed.md). Dynamic types and general user functions remain unsupported. Fixed array inquiries have their own dimension contract (how/are/fixed/array/inquiries/resolved.md).
