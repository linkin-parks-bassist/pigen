Typed assignment contexts supply both packed element type and unpacked shape through pigen_resolve_shaped_assignment_value in expression_resolve.h/expression_resolve.c. Static/automatic local initialization and ordinary typed assignments use this owner. It resolves positional, nested, replicated and constant index/default patterns, conditional arms and fixed-array values. Explicit entries cover one immediate element/subarray. Defaults can descend through unmatched dimensions; they do not relax explicit-entry rank checks. Duplicate/out-of-range/unknown keys, duplicate defaults, incomplete coverage and nonpositive/nonconstant replication reject. Type keys, ordinary unpacked concatenations/slices, dynamic arrays and unpacked typedef casts remain integration work.

Whole-array copies follow IEEE 1800-2017 §§6.22.2 and 7.6: equal rank and per-dimension cardinality, with equivalent packed element width, state domain and signedness. Bounds/directions may differ; correspondence follows declaration order. This is stricter than the assignment conversion supplied to each explicit pattern entry. Explicit/default values receive each element's assignment sizing and conversion context; direct unbased fills fill each element. Array matching/default descent follows §10.9.1 ([standard](https://fpga.mit.edu/6205/_static/F25/documentation/1800-2017.pdf)).

semantic.h/semantic.c own PIGEN_EXPR_ARRAY_PATTERN and pigen_expr_add_array_pattern. Each node has the target element data_type, complete unpacked shape and one converted child per immediate element. Construction checks cardinality, child type and trailing shape, copies children before arena growth and publishes no partial expression/child range on failure. Unpacked aggregates have no packed constant recipe. Element expressions retain their scalar constant identities and X/Z bits. Contextual resolution rolls back expression/child/width-constraint counts on failure; idempotent interning remains permitted. Rank is bounded at 128; fixed storage expansion obeys maximum_generated_bits.

Expression-use analysis, symbol-reference checks and input-alias reconstruction traverse aggregate children. Static initialization keeps startup metadata; automatic initialization keeps lexical entry assignments and normal ownership/peek rules (how/are/static/procedural/initializers/represented.md; how/are/automatic/procedural/initializers/represented.md). rtl.h/rtl.c own PIGEN_RTL_EXPR_ARRAY_PATTERN; lowering preserves element order and sv_emit.c emits nested native assignment patterns while objects retain unpacked declaration shapes. No flattening into packed concatenations supplies array semantics.

Evidence: tests/unpacked_initializer_test.py compares 1,024 native-SV results for pattern forms, bound mapping, packed records, startup copies and automatic entries, and checks output-preserving errors. Its Verilator oracle makes unsupported recursive default descent explicit and spells constant keys numerically. tests/native_foreach_test.py array_initializer profiles score all AXI families through six buffered lanes and 128 reset epochs. These profiles use Verilator simulation because Icarus lacks the required data-array assignment-pattern elaboration. tests/semantic_test.c checks deep shapes, copied children, invalid publication and X/Z retention; tests/rtl_test.c checks terminal aggregate constructors. examples/native_axi_array_observer.pigen demonstrates Stream/Lite/full AXI fabrics and per-entry observations, with independently checked 24/48-bit address and three-lane child overrides under fatal lint.
