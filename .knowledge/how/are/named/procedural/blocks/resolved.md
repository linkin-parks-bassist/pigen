Selected typed always_comb blocks accept begin : name and an optional matching end : name. Nested labels provide lexical paths to directly declared static variables and constants, including ordinary packed fields and type inquiries. Labels do not alter statement ordering or initializer lifetime. Pure ordinary-SV processes retain their existing preservation path.

syntax.h stores procedural_block.has_name/name; syntax.c checks label syntax and matching closing names. semantic.h adds PIGEN_SYMBOL_PROCEDURAL_SCOPE, whose object.scope binds a child procedural scope. pigen_symbol_bind_procedural_scope validates symbol kind, parent identity and procedural ownership; binding the same scope is idempotent and rebinding another rejects. Scope names occupy the ordinary declaration namespace, so duplicate labels and variable/label collisions reject. Structured source namespace validation checks procedural labels against generate labels before selection (how/are/generate/block/name/conflicts/validated.md).

resolve.c reserves immediate named-block symbols before resolving that lexical block's statements, including labels under if/case bodies. This prevents a forward name from accidentally selecting an outer value. Each entered block gets its private lexical scope; its symbol binds that scope before declarations and executable statements resolve. Declaration order remains enforced. A reference to members before the block body has been elaborated currently rejects; full forward static elaboration remains work.

expression_analysis.c shares named-path traversal with generated scopes. A procedural-scope symbol selects its bound scope without an index. pigen_symbol_lookup_local resolves only actual members and follows canonical aliases, without escaping to an enclosing scope. This preserves native foreach static-local identity across specialized branches even when the canonical declaration belongs to the first branch's scope. Missing members, indexed procedural blocks, hierarchical access to automatic variables and attempts to use a scope as a value reject. Named packed-record members continue through the ordinary typed projection owner.

RTL lowers resolved locals to private scope-qualified objects and ordered block statements; authored labels do not supply terminal names or hardware semantics. One-time initialization remains owned by how/are/static/procedural/initializers/represented.md; automatic entry initialization and hierarchical-access restrictions by how/are/automatic/procedural/initializers/represented.md. Cross-process/retained hierarchical access, forward body elaboration and clocked/mixed named blocks need further integration; this support does not establish them.
