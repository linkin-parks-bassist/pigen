Packed records use ordered direct-member syntax, unsigned concatenated DATA types and typedef aliases, with the first member most significant. type_syntax.c collects each record's direct members separately while recursively parsing nested types, then publishes their contiguous range after descendants. This prevents double-counting inline nested fields. tests/syntax_test.c checks nested-first/nested-last ranges; tests/native_protocol_test.py checks correct 32-bit inline DATA at standard pins across all AXI families, directly and through child/fabric routes.

Anonymous nested records preserve private schema identities and typed members through aliases. Nested projections, signed comparisons and contextual nested patterns pass direct/child/fabric standard-pin tests across all AXI families. how/are/anonymous/packed/record/schemas/represented.md owns schema caching, namespace isolation, nominal identity and focused evidence.

pigen_struct_member_for_type follows stored typedef alias targets to record schemas. Metadata belongs to each typedef symbol: member name span, resolved DATA type and least-significant-bit offset. Typed reads become semantic selects retaining member identity and type; static record paths lower as named SV fields (how/are/ordinary/packed/record/sub-projections/lowered.md), while packed channel/computed paths retain their coordinate lowering; writes to static records update that range, while buffered destinations require whole values. Analysis snapshots shapes before appending coordinates. Materialization uses pigen_expr_add_typed_select to preserve signedness and family. Constant typed selects retain raw selections plus explicit type conversion, sharing the bit-level evaluator for four-state comparison and known unsigned elaboration (how/are/constant/packed/selections/evaluated.md).

Owned scalar and packed-record DATA typedefs emit parsed SV declarations at compilation-unit, module and package scope, rewriting numerical widths and signedness. Unowned typedefs retain authored SV; selected generate templates use semantic emission. how/are/data/typedefs/emitted.md owns emission and independent helper/native-pin evidence.

Unknown members, missing member names/semicolons and unterminated records diagnose. Buffered member writes reject with `buffered signal destination must be written as a complete value`. tests/struct_member_write_tb.sv checks static field writes and readback.

Source owners: type_syntax.c parses member ranges; type_resolve.c composes aggregate width/state; resolve.c publishes typedef schemas; expression_analysis.c, expression_resolve.c and semantic.c preserve typed projections. RTL lowering composes constant numerical subranges/indices into containing records to avoid invalid chained SV selects. Native pin tests cover numerical address reads, signed DATA comparisons and constant field selections with ternaries. Dynamic indices, indexed slices and multidimensional packed DATA use typed combinational aliases (how/are/native/axi/field/projections/lowered.md). Endpoint-array support and remaining ordinary-struct/generate contexts are owned by how/are/native/axi/endpoint/arrays/represented.md.

Static record declarations retain prepared inline schemas, allowing ordinary retained assignments and helper calls to access fields on the actual emitted objects. how/are/static/packed/record/declarations/emitted.md owns that boundary and independent signed/X/Z/range/native-pin evidence. Typed projections retain their separate semantic path; broader ordinary-SV contexts still need auditing.
