include/pigen/rtl.h exposes an owned pigen_rtl_source_reference arena in pigen_rtl_model. A reference records module, semantic scope/signal provenance, source_path, emitted_name, role and an RTL object or instance identity. Roles distinguish selected scopes, values, VALID/READY, storage-input sides, native fields, child instances and instance ports. Scope records carry the flattened lexical-name prefix. One source channel can map to several interface/storage objects; source aliases are retained as separate references rather than overwritten.

src/rtl_lower.c:lower_source_references publishes the relation during pigen_lower_rtl_module, after declaration and generated-instance lowering have assigned terminal names. Source paths are module-local. They use external generate names, signed iteration coordinates and declared native array coordinates, e.g. genblk1.lanes[-1].local_bus[1].aw. Native channels retain their identities, with beat as the canonical Stream channel. Standard fields append their field names; child source paths include the instance and declared port. Native child pins map canonical channel/field paths to instanceName.standard_pin, using resolved contracts and connection records. Ordinary child ports retain their declared names. Controls and storage-side roles are metadata distinctions, not additional authored syntax. Anonymous procedural blocks introduce no authored path component: shadowed locals can share source_path text while scope and signal identities distinguish their references and private emitted names. Consumers must retain those identities rather than keying only by source_path.

pigen_rtl_source_reference_add validates module/target ownership and role shape, copies both strings and returns a stable arena index. Identical publication is idempotent; a conflicting emitted name or invalid request returns SIZE_MAX without appending. pigen_rtl_source_reference_get bounds-checks the index. Cleanup frees all strings and the arena; consumers can inspect the map after semantic, syntax, preprocessing and source owners are released. Synthetic objects without a source endpoint are outside this relation. Raw retained SV is not assigned a new hardware namespace by this map.

rtl_module_for_semantic checks the RTL module arena after its memo lookup, so revisiting a module after another module reset the memo recovers its existing owner. Unowned pigen_rtl_module_add records carry invalid semantic provenance; only owned records participate in recovery. This prevents duplicate owners and keeps reference target identities stable across repeated module composition.

tests/generated_instance_test.c checks all three AXI families through anonymous outer scopes, negative-index loops, local endpoint arrays, forward sibling chains, typed child views, standard fields and ordinary bound ports. It checks source and emitted paths, target ownership, repeated publication, conflicts, invalid handles and strings after upstream-model cleanup. External template naming: what/are/automatic/generate/block/names.md. Generated child lowering: how/are/generated/child/instances/lowered.md. The map does not change authored lookup or emitted interface behavior; retained-SV/native namespace and driver integration remain separate work.
