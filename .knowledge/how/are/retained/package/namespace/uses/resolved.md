Retained package functions/tasks contribute lexical namespace facts without executable IR. Bare references can activate enclosing package wildcard imports, so later wildcard exports expose genuinely used declarations. Arguments, locals, block labels, loop indices, members and body-local imports remain lexical. Routine representation: how/are/retained/package/subroutines/represented.md; completed-scope call binding and canonical emission: how/are/retained/package/calls/bound.md.

syntax.h owns pigen_syntax_retained_scope (parent/location) and pigen_syntax_retained_name (reference, parenthesized call, bare call, argument, declaration or import; scope, expanded name/package tokens, wildcard). RETAINED.retained_subroutine records first_scope/scope_count and first_name/name_count ranges. syntax.c:retained_subroutine_namespace builds facts while retaining the body. Checkpoints restore arena counts; pigen_free_syntax_tree frees them.

retained_declaration distinguishes type prefixes, dimensions/defaults, ANSI continuations, old-style formals, variables/parameters/typedefs and direct enum names. Struct/union members get private scopes. retained_namespace_statement models nested/named blocks, for/foreach lifetimes, branches/cases, loops, imports and timing/fork wrappers. Bare identifier statements become call facts. retained_references excludes qualified members, object fields, named arguments and aggregate field keys. Dimensions precede their name declaration. This is bounded namespace discovery, not retained-SV type checking or execution. The scanner also supplies lexical barriers and parsed primary/write facts for module retained native observations (how/are/retained/native/axi/observations/represented.md); package namespace replay remains separate from executable lowering. Formal direction and actual/callee facts support ownership checking (how/are/retained/subroutine/argument/effects/checked.md).

resolve.c:bind_retained_package_uses creates scopes and replays declarations/imports/value references in order. PIGEN_SYMBOL_RETAINED_LOCAL has invalid DATA/hardware identity. Normal lookup and duplicate/import rules apply; old-style repeated direction/type declarations leave full legality to the backend. Shared pigen_import_package and resolve_text_at activate names in their owning scope. Local imports cannot leak into package exports. Ambiguous imports, conflicts and removed native types diagnose at original locations. Semantic lookup consumes parsed facts without rescanning opaque text.

Scope mappings survive until package completion. bind_retained_package_calls then resolves call facts in source order before wildcard exports finalize. Calls see end-of-scope bound declarations/imports and source-point wildcard candidates through pigen_symbol_resolve_call_text_at. Value references retain source-point binding. Canonical call records drive prepared SV names and actual routine imports; details and backend evidence belong to the call owner.

Opaque local imports remain backend-owned: explicit names create barriers, while opaque wildcards prevent speculative enclosing-name activation in their subtree. Such imports cannot establish structured exports through unmodeled namespaces. Generated enum names, richer retained grammar, package variables/classes/DPI/extern and typed evaluation remain work.

Icarus compares original/emitted values where supported; Verilator simulates remaining forms. Backend exception: why/is/the/nested/wildcard/import/regression/simulated/with/icarus.md. Six retained_export profiles in native_protocol_test.py/native_array_test.py independently score all channel pins across three AXI families through routed endpoints, generated arrays/type keys, storage, stalls and queued reset. Width/depth constants become exported solely through retained function references.
