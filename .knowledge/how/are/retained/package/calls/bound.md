Ordinary retained package calls use completed lexical namespaces while value references retain source-point lookup. This supports later explicit function/task imports, later local routine declarations, nested local imports and earlier wildcard activation without changing typed Pigen intrinsic lookup. Typed subroutine evaluation remains separate work. Lexical facts: how/are/retained/package/namespace/uses/resolved.md.

syntax.h/syntax.c distinguish PIGEN_RETAINED_CALL from ordinary references and PIGEN_RETAINED_BARE_CALL for argumentless call statements. resolve.c:add_package retains namespace scope mappings through package completion. bind_retained_package_uses resolves declarations/imports/value uses in order; bind_retained_package_calls visits calls in source order before final wildcard exports.

semantic.c:pigen_symbol_resolve_call_text_at searches each scope's declarations and bound imports through its end, but admits wildcard candidates only before the call. A selected wildcard binds in its owning scope at the original call position. Ambiguity reports without guessing a target. Ordinary resolve_at/resolve_text_at keep their source-point visibility. Basis: IEEE 1800-2017 §26.3 ([standard](https://fpga.mit.edu/6205/_static/F25/documentation/1800-2017.pdf); [committee proposal](https://www.accellera.org/images/eda/sv-bc/att-8865/1809-v7.pdf)).

pigen_retained_call_bind publishes pigen_semantic_retained_call records containing the expanded callee token, canonical target/package symbols and bare-call flag. It canonicalizes aliases, requires a package-owned RETAINED_SUBROUTINE, deduplicates identical bindings and rejects contradictory bindings. Native-actual signature checking also uses these records for selected bare package callees in module retained contexts, keeping emitted lookup consistent with the checked signature (how/are/retained/subroutine/argument/effects/checked.md). These records create no expressions, signals or hardware. The semantic model owns/frees their arena.

output.c:retained_subroutine_text renders chosen callees as original_package::routine. Ordinary spans preserve surrounding bytes; macro spans use expanded tokens so function-like macro arguments survive. Bare calls acquire empty parentheses. Escaped identifiers receive terminating whitespace. prepare_retained_package_imports publishes actual canonical routine imports immediately after each package header, before candidate wildcards. Original imports remain idempotent; DATA/constant imports keep their existing positions. Terminal emission consumes prepared text without namespace resolution. The backend rationale and simulator-specific witnesses belong to why/are/package/callees/and/imports/rendered/canonically.md.

Evidence: tests/semantic_test.c checks split visibility, candidate cutoff, activation position, ambiguity, canonical aliases, record validation and unchanged hardware counts. tests/native_protocol_test.py:forward_package_call_tests compares 897 function values with independent qualified references, 128 task values, a bare-task observation, macro argument preservation and failed-output preservation. Qualified exports remain covered with Verilator where Icarus rejects qualified re-exported function access. Six forward_call standard-pin profiles in native_protocol_test.py/native_array_test.py cover all three AXI families, routed storage/endpoints, generated arrays/type keys, stalls and queued reset; their benches also check the selected helper and exported function. ASan/UBSan checks cover these suites and profiles.
