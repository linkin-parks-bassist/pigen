## Retained inactive design

Native AXI4-Lite and AXI4 fabrics accept `s -> m at [BASE:LIMIT];`, using inclusive global address windows. Bounds resolve in lexical scope, including parameters and genvars. Pigen parent calls specialize module overrides before decoding; maps need no literal rewrites. They must be known nonnegative values representable in 64 bits and fit the endpoint address width, with BASE <= LIMIT. Every outgoing link from a shared source requires a window. Windows must be pairwise disjoint and destinations distinct; at most 32 outgoing links are supported. Window annotations reject on direct, Stream and ordinary scalar links. Even one explicit window enables decode-error handling outside its range.

src/syntax.c retains optional bound expressions; src/resolve.c publishes has_window/address_base/address_limit in pigen_semantic_protocol_fabric_edge. Existing role, complete protocol, timing and ownership checks apply. src/fabric_lower.c creates per-edge five-channel virtual endpoints around pigen_axi_demux, then connects each destination through skid or arbitration. Full AXI ID adaptation occurs after decoding and before target arbitration; reverse responses strip target provenance before returning to the source decoder. Parent ports, child endpoints, generated links and typed standalone fabrics share this lowering. Native boundary storage remains active.

rtl/pigen_primitives.sv:pigen_axi_demux has packed disjoint BASES/LIMITS and independent AW/AR starting-address decoders. Requests retain global addresses and all fields. The primitive permits one outstanding write and an independent read. It captures AW/AR and ownership; a two-entry W queue accepts data before AW. W follows the selected write target through WLAST (one beat for Lite), retaining ownership through upstream B acceptance. Reads retain ownership through upstream RLAST. Target AW/W can complete in either order. Native channel buffering can accept a response before the external master consumes it.

Unmapped writes forward no AW/W, drain W and return DECERR with captured AWID and zero BUSER. Unmapped full reads produce ARLEN+1 DECERR beats, including 256, with zero data/USER, captured ARID and final RLAST; Lite returns one beat. Normal responses preserve target fields. Held channels remain stable; synchronous reset clears pending state and queued W. Configuration checks reject invalid layouts and windows.

The starting address selects the entire burst. Sources must provide legal bursts and WLAST; no translation, burst splitting or malformed-transaction repair occurs. AW/W realignment follows Arm IHI 0022F.b A3.3 ([protocol](https://documentation-service.arm.com/static/5f915bbcf86e16515cdc3b23)).
