pigen_specialize_parameterized_instances returns an owned replacement only when assembled text differs from its input; byte-identical rendering returns NULL without an error. pigen_specialize_fixed_point repeats until unchanged and returns owned final text. Production allows 256 rounds and 64 MiB transformed source. Exceeding either limit errors without partial output. These limits constrain rounds/text rather than peak allocation.
