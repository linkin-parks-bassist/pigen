Casts and declarations share pigen_syntax_type_id, one type-record arena and ordered type-argument arena. A syntax type has optional written base token, signedness, complete location and ordered count/range arguments whose bracket payloads are expression IDs. Expression and type structures refer mutually by IDs and use syntax_common.h for location/error/signedness to avoid C include cycles; semantic_error.h supplies shared diagnostics. Cast owns type ID and separate value child, never an expression-as-type placeholder. pigen_parse_type_prefix consumes expanded source, bounded token extent and expression/type arenas, returning type and after token; parse each bracket once. Shared resolution first resolves constant arguments with data-type-owned spelling-domain literal policy, normalizes proved positive exact counts into structural symbolic widths, asks pigen_data_type_from_spelling, then typedef lookup. int/uint require one positive integral count and no redundant signedness; ordinary ranges retain written direction, implicit bases retain absence. Negative/zero count errors point to argument. Declarations/casts do not own primitive tables or parse captured text. Postfix selection of cast result remains legal. Tests cover uint[8]'(value), word_t'(value), logic[15:0]'(value), shared IDs/count versus range/value child/full span, empty count/malformed range/missing parentheses/expression-as-type rejection. Owner files type_syntax.h/c, type_resolve.h/c, syntax_common.h, semantic_error.h with parsing/resolution build edges. Older byte spelling in examples is superseded; ordinary signed SV byte is reserved and remains opaque where unsupported.
