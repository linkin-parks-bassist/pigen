## Retained design and witnesses

The archived-native-protocol-test recipe requires a pre-quarantine compiler for these fabric witnesses. Composition checks use real native cores, independent standard-pin masters/scoreboards, warnings-fatal Verilator lint and Icarus simulation. They supplement synthetic transport/arbitration and make cores-test.

- tests/native_axi_core_fabric_test.py runs Stream FIFO, Lite registers and full bridge through direct, routed, two-hop, parent-boundary and parameterized typed standalone fabrics. Three transaction/stall seeds per profile cover 63 boundary/hierarchy designs. Internal bus storage profiles are removed under the boundary-only AXI declaration policy. Typed standalone WIDTH is overridden from 64 to 32. Existing independent core transaction oracles check memory-mapped behavior. Source, RTL, benches, commands and CSV/VCD evidence remain in build/native-core-fabrics.
- tests/native_core_contention_test.py includes three-master fan-in into the actual Lite register bank/full bridge at three seeds. Full AXI has colliding two-bit source IDs, four-bit target IDs, independent AW/W offers, four/eight-beat FIXED/INCR/WRAP, all byte masks, zero strobes and invalid descriptors. Per-source golden memory is independent of the backend. Every backend write/read checks address, order and count; writes also check payload/strobes. B/R data, IDs, status, RLAST and stalled stability are scored. Shared reset flushes accepted pending traffic.
- Its switched profiles add two actual core targets, with two masters for Lite and three for full AXI, at the same three seeds. A typed standalone switch child consumes a contextual collection pattern; generated parent links add a second address-decoding level through child endpoint arrays. The unchanged real cores connect through standard pins in the independent SV bench. Lite splits global addresses 0–7 and 8–15 between register instances. Full bridges preserve global 0–4095/4096–8191 addresses and have separate backend memory agents. Masters alternate targets while retaining independent golden state. Physical target AW/AR monitors require exact request counts and full-AXI source-ID prefixes derived from the authored collection order, rejecting misrouting or escaped decode misses. Unmapped reads/writes receive DECERR without reaching cores; invalid mapped descriptors exercise core errors separately. Explicit AW-first/W-first/simultaneous offers, colliding IDs, byte strobes, bursts, response stalls and queued reset remain checked. Target 0 refuses AW/W/AR until cycle 800; a different master must complete B and R through target 1 during that interval after reset, proving independent target progress. Evidence remains in build/native-core-contention/*-switched.
- tests/native_axis_fabric_test.py includes the real Stream FIFO behind two, three and five contending sources. Independent packet/beat scoreboards verify DATA/KEEP/LAST, ownership, fairness, backpressure and queued reset. Core synchronous active-high reset translates from the parent's active-low binding.

These are finite simulation profiles. The full bridge has no exclusive monitor; its profile belongs to what/is/the/axi4/burst/bridge.md. Synthetic exclusive monitors verify fabric ID provenance separately. Stream packet/beat merges use boundary and child endpoints. Synthetic five/seven-source trees independently check cumulative tags, reverse response stripping and exclusive monitor identity through successive merge stages (tests/native_axi_fabric_test.py; how/are/native/axi/fabrics/connected/and/arbitrated.md). Broader language contexts remain separate compiler work unless a concrete interface/fabric example proves the dependency. Overall module-interface/fabric acceptance is tracked in what/is/the/native/axi/acceptance/status.md.
