Pigen is a C17 source-to-source compiler extending SystemVerilog with ready/valid transfers, elastic pipelines, FSMs and routed fabrics. It emits synthesizable SV and storage primitives. Employer/partner/customer material is excluded.

**pigen-fork** is a delivery fork of /home/david/Projects/pigen. The production `./pigen` is the structured frontend (src/pigen.c through src/compile.c): preprocess, data-first syntax, semantic types/expressions/scopes, RTL lowering, naming, output model and SV emission. The classic textual CLI is removed; prototype sources remain quarantined references.

Core transfers, partial pipelines, FSMs, validity actions, parameterized children, parent child-port endpoints and buffered fabric routing with arbitration/SVG are implemented. The standard-core library and its verification profiles are owned by what/is/the/standard/cores/library.md; make cores-report builds its artifact gallery. Repeated-name pipeline updates currently reject; how/do/pipeline/stage/reads/work.md owns the gap. See what/is/broken.md for capability limits and what/is/the/plan.md for remaining work.

Native axi4_stream/axi4_lite/axi4 provide typed channels, standard pins and buf/fifo/skid storage (how/to/write/native/axi/declarations.md). Provisional extern-module contracts connect separately compiled SV IP (how/are/native/axi/endpoints/mapped/to/external/systemverilog/ip.md). Explicit/implicit if/for/case generate scopes support clocked code, ordered always_comb with static/automatic locals (how/are/automatic/procedural/initializers/represented.md) and lexical blocks (how/are/named/procedural/blocks/resolved.md), cases, loops with exits and fixed-array/packed-field/native-collection foreach (how/are/combinational/foreach/loops/represented.md), FSMs, pipelines, endpoints, children, named paths and fabrics (how/are/structured/generate/scopes/elaborated.md). Scalar and selected-array bindings, projections, siblings and timing checks pass all-family simulations (how/are/native/axi/endpoint/arrays/represented.md). Whole-bus direct/routed fabrics accept ports, child views, internal storage and collections, including typed standalone declarations (how/to/write/typed/standalone/fabrics.md), with Stream TDEST switching, memory-mapped inclusive address windows (how/does/native/memory/mapped/address/routing/work.md) and typed arbitration; how/are/native/axi/fabrics/connected/and/arbitrated.md owns their limits. Memory-mapped contention preserves write/read ownership and passes independent real-core burst/backend tests. ID tagging preserves exclusive monitor identity under contention. Normal/when/FSM packed-record patterns support nesting, ternaries and casts. Unpacked initializers: how/are/unpacked/data/assignment/patterns/resolved.md. Native fields support runtime indices/slices and multidimensional packed DATA through typed combinational aliases, including constructed records and peek(record).field (how/are/native/axi/field/projections/lowered.md). Retained module/global calls observe stored fields and check directions (how/are/retained/subroutine/argument/effects/checked.md). The standard AXI cores use native endpoints and named records with independent standard-pin scoreboards. Native typedefs: how/are/native/axi/type/aliases/represented.md; package contracts/constants: how/are/native/axi/package/types/represented.md; explicit/wildcard imports: how/are/native/axi/package/imports/resolved.md; ordinary dependencies: how/are/ordinary/package/dependencies/resolved.md. Richer routing/projections and contextual patterns remain active work.

Qualified typed if chains preserve checks across FSM termination and pipeline guards (how/are/qualified/if/statements/represented.md). Combinational cases preserve qualifiers and branch entry (how/are/combinational/case/statements/represented.md). Pure clocked cases use typed matches and edge checks (how/are/clocked/case/statements/represented.md). Fixed-bound clocked foreach specializes transfer bodies and lexical exits in declaration order (how/are/clocked/foreach/loops/represented.md). Cases preserve common width/signedness, wildcard matching and priority against native references. Existing unqualified function/transfer cases retain combinational SV decoders and scalar guards; effectful mixed qualification/scheduling remain open.
