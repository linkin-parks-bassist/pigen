Native receiving channels use owned storage to isolate external AXI handshakes from Pigen token consumption. In src/rtl_lower.c, native input signals take the storage lowering route with internal payload/valid/pop controls. lower_protocol_ports creates separate external VALID/READY pins and packs all input fields into the storage's input packet. FIFO/skid READY follows registered occupancy; a buf receiver accepts only while empty, preserving one-slot capacity while cutting its downstream-ready replacement path. Ordinary Pigen input boundary semantics are unchanged.

Arm AXI's clock/interface requirements prohibit combinational paths from interface inputs to interface outputs. The primary reference is IHI 0022, Clock and Reset/AXI Transport: https://documentation-service.arm.com/static/651c285c15583d1bff972f94. Native receiving capacity and transmitting registered payload/VALID isolate the tested relay interfaces from external input changes between clock edges.

The active native-protocol-test boundary profiles exercise all three families with buf/fifo/skid, independent channel stalls, complete sidebands and reset with queued traffic. Its first phase stalls every receiver and requires exact total relay capacity: two buf slots, four skid slots or six fifo[3] slots across input/output storage. It then resets with full queues and independently scores 257 new records per channel. A between-edge snapshot check changes input data/VALID/READY and requires physical outputs to remain unchanged. Named field observations refer to the outgoing stored token, whose identity remains valid despite receive buffering.

Clock/reset binding and within-module domain reconciliation are implemented (how/are/native/axi/clock/domains/bound.md), including renamed controls and active-low synchronous reset. Child bindings also translate and validate parent timing identities. Hierarchy tests score channel/sideband transport, exact capacity, reset recovery and isolation through manual, named/positional and forward sibling connections. Native fabric integration is quarantined and not in use. Earlier fabric isolation/transaction witnesses are retained for architectural review; they are not an active completion requirement (how/are/native/axi/fabrics/connected/and/arbitrated.md). Source syntax is owned by how/to/write/native/axi/declarations.md. The full objective remains in what/is/the/plan.md.
