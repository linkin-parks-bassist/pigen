The structured frontend and elastic RTL work remain incomplete. Passing focused tests do not establish full compiler acceptance.

- **Task 8 fire-identity entry point prints debug traces to stderr.** The landed pigen_lower_rtl_transfers (src/rtl_lower.c) still carries six fprintf(stderr, "DBG: ...") calls in its process/transfer loop (the lowered clock, each transfer's fire identity, the destination lvalue, the source-ready equation, the destination update, and each published process). A compiler that emits SV must not print diagnostic traces on an ordinary successful lowering. This shipped with the first-pass entry-point wiring and should be removed with the next transfer-lowering change.
- **Co-slice gives the last destination the whole aggregate.** For a multi-destination co-sliced transfer the prototype assigns the full packed aggregate to the last destination instead of its slice. In `tests/coslice.pigen` (four 8-bit destinations) the emitted `state_delay <= ({source + 8'd1, source + 8'd2, source, state});` assigns 32 bits to an 8-bit register; `tests/transfer_block.pigen` emits the same pattern (24 bits into 8). Verilog's implicit truncation keeps the low bits, which here happen to be the correct slice, so `coslice-test` and the other simulations pass. Verilator reports both as `WIDTHTRUNC` warnings, which `make verify` does not treat as failures (its lint runs with `-Wno-fatal`). This violates the packed bit-stream order contract and would produce wrong values whenever the last destination is not the lowest slice.
- **Task 6 declaration lowering is complete, but the elastic RTL vertical slice is not.** pigen_lower_rtl_module_declarations dispatches by the source descriptor's realization through a private realization-indexed adapter table (no source transfer-type enum value appears in src/rtl_lower.c). ELASTIC_SLOT / PULSE_REGISTER / PARAMETERIZED_QUEUE / SKID_QUEUE each publish exactly one VARIABLE payload object (the lowered data type via the type memo, the semantic direction, the input side the same object) plus exactly one pigen_rtl_instance owned by the semantic module, the parameterized queue carrying its semantic depth (lowered from the transfer argument const-expr through the expression memo) as the instance's single ordered parameter so the value round-trips exactly, and valid/ready driven by the primitive so no constant control expression is published.
