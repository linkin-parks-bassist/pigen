The structured frontend and elastic RTL work remain incomplete. Passing focused tests do not establish full compiler acceptance.

- **Conditional co-sliced transfers are broken on master.** The co-slice fix (accepted main, commit 55a684d) replaced $bits() in the repartition shift amounts with constant destination widths extracted from data types, but deleted the transfer->count, prefix_end, width_lhs, width_rhs, width_rhs_length and requires_exact_width assignments from pigen_extract_signal_transfer (src/assignments.c). The conditional-transfer path in src/pigen.c consumes those fields and fails with "conditional transfer requires declared signals" for any conditional co-sliced transfer, so make coslice-test fails on the accepted main (verified at 55a684d; the same base 2b6ec20 compiles tests/coslice.pigen cleanly).
- **The co-slice width-truncation defect survives the fix.** For a multi-destination co-sliced transfer the last destination still receives the whole packed aggregate: in the 2b6ec20 emission `state_delay <= (({source + 8'd1, source + 8'd2, source, state}));` assigns 32 bits to an 8-bit register, and the fix only rewrites the shift amounts, not that assignment. Verilator reports it as WIDTHTRUNC; this violates the packed bit-stream order contract and would produce wrong values whenever the last destination is not the lowest slice.
- **The elastic RTL vertical slice is functionally complete on master.** Tasks 6, 8, 9, 10, 11 and 12 are complete (Task 7 ready-cycle validation deferred to Pigen 1.0): the terminal emitter renders a finished, named RTL lowering to SystemVerilog validate-first with no partial output; the quarantined composer pigen_compile_source wires the full pipeline and the vertical-slice-test target compiles and simulates with Icarus. Remaining in-order work is the step-5 repair above. Task status is owned by what/is/the/plan.md; contracts and evidence by the narrow task leaves (what/is/elastic/rtl/task/six.md through twelve).
- **Structured frontend is unlinked from production ./pigen.** The production Makefile target still compiles the textual prototype rather than the structured syntax, resolution, semantic and RTL path. See does/the/structured/frontend/run/in/production.md.
- **Retained-subsystem build and frontend gaps.** Core, pipeline, FSM, child-instance and fabric are specified from the spec and built on the structured path, subject to what/are/the/remaining/architecture/migration/gates.md. Accepted parameter/type/aggregate/array/expression forms and macro concatenation/stringification/required arguments remain incomplete. Delete textual machinery only when the corresponding retained subsystem's structured path covers the spec.
- **make verify on the accepted main passes but does not fail on lint warnings.** Its Verilator lint runs with -Wno-fatal (30 invocations in tests/smoke.sh plus one in the Makefile), so width warnings such as the co-slice truncation pass silently. A test contract that removed all -Wno-fatal and registered verify in tests/contracts.json was accepted at commit 35f6352, but it branched from the same base as the co-slice fix and is not contained in the accepted main, so main still carries the flag.
