Capability boundaries follow what/is/the/spec.md, how/to/connect/child/ports.md, what/is/elastic/rtl/task/five.md and how/to/run/repository/verification.md.

Partially supported surfaces include data-first declarations, abstract inputs, static/buffered transfers, pipelines, FSMs, transfer events, handshake/peek intrinsics, validity actions, multiple modules, child endpoints, specialized instances, generated scopes, direct/routed fabrics, concatenation destinations, typed/integer parameters and contextual records. Ordinary SV preservation has witnessed interface/enum/union/struct modules, async-reset and multi-edge processes, directives, functions and declarations. Specific contracts and acceptance evidence belong to their mechanism owners; compilation alone does not establish correctness.

Defects and gaps:
- **Pipeline field versioning is missing.** Production rejects later-stage x <= x + 1 as self-consumption. The contract and reproducer are in how/do/pipeline/stage/reads/work.md; distinct-name tests do not validate fixed-namespace pipelines.
- **Native type aliases remain partial.** Global/local aliases pass direct/parameterized/generated child, collection and fabric witnesses across all families. Packed type inquiries/casts reject. Qualified package typedefs/constants and common explicit/wildcard import contexts work. Ordinary inline package functions/tasks coexist with DATA/contracts and retain their bodies/names. Typed subroutine evaluation, classes/DPI/extern/prototypes, package variables, package enum/union typing, generated enum names, opaque imports and other retained/value-shadow contexts remain work (how/are/retained/package/namespace/uses/resolved.md; how/are/retained/package/subroutines/represented.md; how/are/native/axi/package/types/represented.md); simple named native type keys are supported in child collection patterns (how/are/native/axi/type/aliases/represented.md).
- **Native coordinate constants remain partial.** Arbitrary function calls remain unsupported; zero-count packed fields compose with positive-sized constant fields (how/are/native/axi/collection/selections/resolved.md).
- **Native generate contexts remain partial.** Explicit/implicit if/for/case/block scopes support native endpoints, transfers, specialized children, named access and fabrics. Scoped assigns and ordered always_comb block/if/case/loop trees with static/automatic locals and lexical exits are typed. Comma case items retain grouping through RTL and emission. Typed combinational cases support unique/unique0/priority with authored defaults and native checks. Fixed-bound clocked transfer foreach supports lexical exits (how/are/clocked/foreach/loops/represented.md). Effectful qualified mixed cases, clocked foreach declarations and wider fills remain open (how/are/scoped/combinational/processes/represented.md; how/are/procedural/case/operands/resolved.md). Named typed blocks support qualified locals, but forward/retained hierarchy remains work (how/are/named/procedural/blocks/resolved.md). Data-array type keys, concatenations, slices and typedef casts remain work (how/are/unpacked/data/assignment/patterns/resolved.md). Retained observational function arguments pass scoped native tests (how/are/retained/native/axi/observations/represented.md); broader generated/effectful retained-SV integration remains work.
- **Ordered blocking mixed bodies remain partial.** Pure clocked cases use typed matches and edge-qualified checks (how/are/clocked/case/statements/represented.md). Established unqualified function/transfer cases retain combinational decoders and scalar guards. Writable native actuals reject for known retained signatures; opaque/extern signatures remain incomplete (how/are/retained/subroutine/argument/effects/checked.md). Effectful selector scheduling, general sequential cases, function/task effects, loop guards and nonblocking function/Pigen write conflicts remain incomplete or rejected.
- **Ordinary-SV preservation is audit-driven.** Forms beyond witnessed examples need auditing; unsupported forms must be recovered rather than silently dropped or misdiagnosed.
- **Anonymous FSM headers.** Core sources use anonymous headers, but production parsing still accepts legacy optional names. Remove that syntax and update regressions. FSM startup without asserted reset remains undecided; standalone src/fsm_lower.c is not the production route.
- **Event limits.** when supports transfer events; other event kinds remain unspecified.
- **Deferred to Pigen 1.0:** semantic ready-cycle validation and route negative witnesses. Verilator exposes combinational loops; lowering assumes validated identities.
