Ordered output model (output.h / output.c / output_test.c). Layout items are opaque source spans or matching structured module/object/instance/equation/process IDs. Walk syntax child order, keep trivia/separators as opaque spans, require every structured node to have a lowered identity. Gate: exact monotonic coverage, rejecting gaps/overlaps/reversal/wrong-source/invalid refs; failed nested append restores layout/item/child counts and destroy zeroes the model; make output-model-test with rtl-test green.

Shape (implemented): six `pigen_output_kind` kinds (OPAQUE, MODULE, RTL_OBJECT, RTL_INSTANCE, RTL_EQUATION, RTL_PROCESS). `pigen_output_item` holds the kind plus one payload — for OPAQUE a `pigen_source_span`, for a structured kind the matching identity (value copy) — and a `pigen_rtl_record_range layout` (the half-open nested-item range, meaningful for a module, empty otherwise). `pigen_output_model` owns the ordered item array and a parallel per-module `nested_layouts` range array. API: `pigen_output_model_init`, `pigen_output_item_add` (slot or PIGEN_INVALID_ID), `pigen_output_item_open`/`_add_child`/`_layout` (owner-managed nesting), `pigen_output_item_count`, `pigen_output_item_get`/`_kind`/`_span` (out-of-range reads a zero/OPAQUE/all-invalid value), five kind-typed identity accessors, `pigen_build_output_model` (stub: 0 with zero items), `pigen_free_output_model` (frees both arrays, zeroes to NULL/0). No API returns opaque text; the model never validates structured identities against an RTL owner; a failed call returns 0/-1 or PIGEN_INVALID_ID and may leave partial state (how/should/compiler/builders/fail.md).

Nesting ownership (implemented): owner-managed, not caller-set. `pigen_output_item_open` appends a module and opens its range empty at (slot+1, 0), discarding the caller layout, recorded in `nested_layouts` keyed by the module's arena index; `pigen_output_item_add_child` appends a child (count += 1) keeping the module item's `layout` in lockstep (PIGEN_INVALID_ID for an unknown identity); `pigen_output_item_layout` reads the range ({0,0} for no scope/missing/out-of-range; a child-less module keeps {slot+1,0}); the grown tail is zeroed so a sparse identity reads empty until opened.

Coverage gate (implemented): pure read-only `pigen_output_validate_coverage(const pigen_output_model *, const pigen_source_manager *)` walks the model's OPAQUE spans in slot order over one source, reporting the first violation; structured items are skipped and it never mutates the model or manager (result by value). Per OPAQUE span: INVALID when its source is not the manager's single (unresolvable/unknown) source; WRONG_SOURCE when it names a different but valid source; REVERSAL when end <= start or exceeds the source length; OVERLAP when start < cursor; GAP when start > cursor; then cursor = end. A model with no OPAQUE items is EMPTY; a NULL model or manager is INVALID; {1, OK} only on a complete contiguous run ending exactly at the source length. `pigen_output_coverage_reason` is OK/EMPTY/GAP/OVERLAP/REVERSAL/WRONG_SOURCE/INVALID; the result is `{int ok; reason}`.

Build seam: Makefile `output-model-test` compiles tests/output_test.c + src/output.c + src/source.c + src/util.c under -Werror C17 and runs the binary with $(T); tests/contracts.json carries one entry per present section. t9-skeleton pins the shape (zero items on init, span/identity read-back, wrong-kind PIGEN_INVALID_ID, free zeroes); t9-nesting pins the owner-managed nested-range behavior (open (slot+1,0) discarding the caller layout, add_child lockstep, child-less {slot+1,0}, passive and out-of-range slots {0,0}, free zeroes both arrays); t9-coverage pins the gate (the OK/GAP/OVERLAP/REVERSAL/WRONG_SOURCE/INVALID/EMPTY witnesses plus a structured item interleaved between two OPAQUE spans, skipped by the walk).
