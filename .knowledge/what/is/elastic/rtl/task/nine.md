Ordered output model (output.h / output.c / output_test.c): items are opaque source spans or matching structured module/object/instance/equation/process IDs; walk syntax child order, keep trivia as opaque spans, require every structured node to have a lowered identity.

Shape (implemented): six `pigen_output_kind` kinds (OPAQUE, MODULE, RTL_OBJECT, RTL_INSTANCE, RTL_EQUATION, RTL_PROCESS); `pigen_output_item` holds the kind plus one payload (an OPAQUE `pigen_source_span`, or a structured identity by value) and a `layout` range (the half-open nested-item range, meaningful for a module); `pigen_output_model` owns the item array and a per-module `nested_layouts` range array. API: `pigen_output_model_init`, `pigen_output_item_add`, `pigen_output_item_open`/`_add_child`/`_layout` (owner-managed nesting), `pigen_output_item_count`, `pigen_output_item_get`/`_kind`/`_span` (out-of-range reads a zero/OPAQUE/all-invalid value), five kind-typed identity accessors, `pigen_output_error` (the build-walk diagnostic: a node span + borrowed static message) + `pigen_output_error_is_set` (1 when a non-NULL message AND a valid span), `pigen_build_output_model`, `pigen_free_output_model`. No API returns opaque text; the model never validates structured identities against an RTL owner; a failed call returns 0/-1 or PIGEN_INVALID_ID and may leave partial state (how/should/compiler/builders/fail.md).

Nesting (implemented, owner-managed): `pigen_output_item_open` appends a module and opens its range empty at (slot+1, 0) keyed by the module's arena index; `pigen_output_item_add_child` appends a child keeping the module's `layout` in lockstep; `pigen_output_item_layout` reads the range ({0,0} for no scope/missing).

Coverage gate (implemented): pure read-only `pigen_output_validate_coverage(const pigen_output_model *, const pigen_source_manager *)` walks the OPAQUE spans in slot order over the manager's FIRST file only, reporting the first violation and never mutating: INVALID, WRONG_SOURCE, REVERSAL (end <= start or past the file length), OVERLAP (start < cursor), GAP (start > cursor); EMPTY when there is no OPAQUE item; {1, OK} on a complete contiguous run to the file's length. `pigen_output_coverage_reason` is OK/EMPTY/GAP/OVERLAP/REVERSAL/WRONG_SOURCE/INVALID; result `{int ok; reason}`.

Build walk (implemented): `pigen_build_output_model(pigen_output_model *, const pigen_syntax_tree *, const pigen_rtl_lowering *, pigen_output_error *error)` walks the parsed tree in source child order against the completed lowering, emitting OPAQUE spans, a module's nested scope, and each structured node's resolved RTL identity; full rule at the ordered output build walk contract. A NULL model/syntax/lowering returns -1 before any walk and leaves `*error` unset (zeroed when non-NULL); the 4th argument is accepted but otherwise unused by the body in this shape. A structured node with no published identity is still skipped; the missing-lowered-identity diagnostic's public shape is established, its span-reporting and stop-on-error wiring is next.
