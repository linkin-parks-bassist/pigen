Ordered output model (output.h / output.c / output_test.c): items are opaque source spans or matching structured module/object/instance/equation/process IDs; walk syntax child order, keep trivia as opaque spans, require every structured node to have a lowered identity.

Shape (implemented): six `pigen_output_kind` kinds (OPAQUE, MODULE, RTL_OBJECT, RTL_INSTANCE, RTL_EQUATION, RTL_PROCESS); `pigen_output_item` holds the kind plus one payload (an OPAQUE `pigen_source_span`, or a structured identity by value) and a `layout` range (the half-open nested-item range, meaningful for a module); `pigen_output_model` owns the item array and a per-module `nested_layouts` range array. The API: `pigen_output_model_init`, `pigen_output_item_add`, `pigen_output_item_open`/`_add_child`/`_layout` (owner-managed nesting), `pigen_output_item_count`, `pigen_output_item_get`/`_kind`/`_span`, five kind-typed identity accessors, `pigen_build_output_model`, `pigen_free_output_model`. No API returns opaque text; the model never validates structured identities against an RTL owner; a failed call returns 0/-1 or PIGEN_INVALID_ID and may leave partial state (how/should/compiler/builders/fail.md).

Nesting (implemented, owner-managed): `pigen_output_item_open` appends a module and opens its range empty at (slot+1, 0) keyed by the module's arena index; `pigen_output_item_add_child` appends a child keeping the module's `layout` in lockstep; `pigen_output_item_layout` reads the range ({0,0} for no scope/missing).

Coverage gate (implemented): pure read-only `pigen_output_validate_coverage(const pigen_output_model *, const pigen_source_manager *)` walks the OPAQUE spans in slot order over the manager's FIRST file only, reporting the first violation and never mutating: INVALID, WRONG_SOURCE, REVERSAL (end <= start or past the file length), OVERLAP (start < cursor), GAP (start > cursor); EMPTY when there is no OPAQUE item; {1, OK} on a complete contiguous run to the file's length.

Build walk (implemented): `pigen_build_output_model(pigen_output_model *, const pigen_syntax_tree *, const pigen_rtl_lowering *, pigen_output_error *)` walks the parsed tree in source child order (root `PIGEN_SYNTAX_COMPILATION_UNIT` down each `first_child` → `next_sibling`) against the completed lowering: OPAQUE → an OPAQUE item holding `location.source_span`; MODULE → its lowered `pigen_rtl_module_id` opening its nested scope; a structured node → its RTL identity resolved through its semantic record (the record whose `syntax` is the node's index) to the RTL provenance field (`semantic_module`, `semantic_signal`). A NULL model/syntax/lowering returns -1 before any walk; a structured node with no published identity is skipped (the diagnostic is next). The trailing `pigen_output_error` out-param (a `{span, message}` + `pigen_output_error_is_set`; unset on a NULL-argument or clean walk) carries that diagnostic. Contract at what is the ordered output build walk contract.
