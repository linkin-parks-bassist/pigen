Transfers from one fire identity. Extend rtl_lower to combine the canonical guard, the distinct consumer-valid and producer-ready dependencies into one fire identity shared by destination updates and source-ready equations. Lower static lvalues/projections/concatenations, buffered destinations whole, and the assignment conversion above the RHS. One RTL process per semantic process. A failed call reports -1 and the compile stops; it may leave partial state, and no test asserts a failure left the model or maps unchanged (how/should/compiler/builders/fail.md). Exclusive-producer scope binds buffered destinations only — static duplicate writes are legal, source-ordered, each keeping its own fire identity (why/are/buffered/consumers/exclusive.md). The accessors `pigen_module_processes` (module's processes, arena order) and `pigen_process_transfers` (a process's transfers, arena order) are implemented in src/semantic.c; model-owned buffers freed by `pigen_free_semantic_model`, NULL/0 for an invalid or empty owner. The t8-accessor section of tests/rtl_lower_test.c pins the accessor contract green over an extended base witness (a second process and a second transfer on the base process over a distinct payload, arena [first, second]; a zero-process module asserting NULL/0) and ends green at the entry-point assert (pigen_lower_rtl_transfers returns 0); it does not call pigen_lower_rtl_module. The fire-identity helpers (fire_bits_one, fire_and, fire_atom, the memo, fire_identity_for_transfer) and lower_expr are implemented in src/rtl_lower.c; `fire_identity_for_transfer` is the memoized conjunction of the canonical guard atoms, the distinct consumer-valid controls and the distinct producer-ready controls, with the 1-bit "true" BITS node when there are none. `fire_bits_one` returns a distinct non-constant PIGEN_RTL_EXPR_BITS fire-identity node: the constant-expression memo is reused only when the interned slot already holds a BITS node; a slot the declaration lowering published as the INTEGER "valid 1" constant is replaced by a fresh 1-bit BITS literal, and a live BITS node is never clobbered (a repeat call returns the same BITS node). `pigen_lower_rtl_transfers` prints no diagnostic traces on a successful lowering.

The fire-identity gate family now passes: the base single transfer's destination update and source-ready equation value trees share one memoized non-constant BITS node (not the INTEGER "valid 1" constant, not a re-lowered copy). The remaining gate families — join, repeated projection, static-only assignment, process order, module composition, and the guard-and-dependency witness — are separate sections of the same file, each its own `make rtl-lower-test T=<section>` command, each red until its lowering lands and each absent from the file until its test packet lands; the rtl-lower-test manifest carries one entry per present section, so every manifest command passes on master.

Shared fire-identity probe helper. The fire-identity, join, and guard-and-dependency sections each assert that two lowered RTL expression trees share one memoized non-constant node via a single file-local helper (tests/rtl_lower_test.c): it collects every reachable expression identity from each root (identity-based, through the model's child links) and reports whether any shared identity is not a PIGEN_RTL_EXPR_INTEGER constant, so two trees sharing only a lowered constant do not satisfy the contract. The helper is re-established with the fire-identity section and must be present before the join and guard-and-dependency family sections are added, since those sections call it rather than inlining the tree walk.

Entry contracts. `pigen_lower_rtl_transfers(lowering, module)` returns 0/-1; it lowers the canonical guard atoms into the shared fire identity, the destination lvalue (static, projection or concatenation; buffered whole through their declaration endpoints), and the RHS through the expression memo with the assignment conversion above it. `pigen_lower_rtl_module` returns the composed module id (PIGEN_INVALID_ID on failure) via `pigen_rtl_module_add_with_owner`, `pigen_lower_rtl_module_declarations`, endpoint binding, processes, transfers, and the four published ranges.
