Gate families, each a separate section of tests/rtl_lower_test.c (red until its lowering lands; the fire-identity section is the escape-closer because only it carries a real guard and endpoint dependencies, the others seeding zero-atom guards and NULL/0 uses): fire identity (the base single transfer's update and source-ready equation value trees share one memoized non-constant node, not a re-lowered copy); join (two transfers on one static destination share one fire identity); repeated projection (two projections of one payload share one RTL object); static-only assignment (exactly one clocked update of the static payload); process order (two RTL processes in arena order, each owning exactly its own single update on its own payload); module composition (pigen_lower_rtl_module returns the published module identity and its object/instance/equation/process ranges cover exactly the witness's records in arena order); guard-and-dependency fire identity (a one-process module whose single transfer assigns the 1-bit constant 1 under a two-atom guard, g == 1 AND f == 0, with five distinct (signal, role) uses; assert the fire identity reachable from both the destination update value and the source-ready equation value shares one non-constant node, conjoins the two guard atoms and the endpoint controls each reachable exactly once, and is a two-child logical-and).

Shared fire-identity probe helper. The fire-identity, join, and guard-and-dependency sections each assert that two lowered RTL expression trees share one memoized non-constant node via a single file-local helper (tests/rtl_lower_test.c): it collects every reachable expression identity from each root (identity-based, through the model's child links) and reports whether any shared identity is not a PIGEN_RTL_EXPR_INTEGER constant, so two trees sharing only a lowered constant do not satisfy the contract. The helper was removed from the test file when the red families were stripped (an unused static fails -Werror) and must be re-established before any of those family sections can be added, since the sections call it rather than inlining the tree walk.
