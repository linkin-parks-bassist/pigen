Transfers from one fire identity. Extend rtl_lower to combine the canonical guard, the distinct consumer-valid and producer-ready dependencies into one fire identity shared by destination updates and source-ready equations. Lower static lvalues/projections/concatenations, buffered destinations whole, and the assignment conversion above the RHS. One RTL process per semantic process. A failed call reports -1 and the compile stops; it may leave partial state, and no test asserts a failure left the model or maps unchanged (how/should/compiler/builders/fail.md). Exclusive-producer scope binds buffered destinations only — static duplicate writes are legal, source-ordered, each keeping its own fire identity (why/are/buffered/consumers/exclusive.md). Gate: make rtl-lower-test, with rtl-test, rtl-name-test and transfer-type-test remaining green. (ready-graph-test is the deferred Task 7 gate.)

Shape established. `pigen_lower_rtl_transfers` / `pigen_lower_rtl_module` are declared in include/pigen/rtl_lower.h (src/rtl_lower.c). The accessors `pigen_module_processes` and `pigen_process_transfers` (arena order) are implemented in src/semantic.c; model-owned buffers freed by `pigen_free_semantic_model`, NULL/0 for an invalid or empty owner. The t8-accessor section of tests/rtl_lower_test.c pins the accessor contract green over an extended base witness and ends at the entry-point assert (pigen_lower_rtl_transfers returns 0). The fire-identity helpers (fire_bits_one, fire_and, fire_atom, the memo, fire_identity_for_transfer) and lower_expr are implemented in src/rtl_lower.c. `fire_identity_for_transfer` is the memoized conjunction of the canonical guard atoms, the distinct consumer-valid and producer-ready controls, with the 1-bit "true" BITS node when there are none. `fire_bits_one` returns a distinct non-constant PIGEN_RTL_EXPR_BITS fire-identity node: the constant-expression memo is reused only when the interned slot already holds a BITS node; a slot the declaration lowering published as the INTEGER "valid 1" constant is replaced by a fresh 1-bit BITS literal, and a live BITS node is never clobbered (a repeat call returns the same node). `pigen_lower_rtl_transfers` prints no diagnostic traces on a successful lowering.

Module composition landed. `pigen_lower_rtl_module` composes the module record from the transfer lowering's already-published state: it resolves the module through the lowering memo and publishes the record's four owner ranges as the arena-contiguous records created for this module, in arena order — the object range covers the module's signals' payload objects, the equation range its transfers' source-ready equations, and one RTL process per semantic process (arena order) each owning exactly its own transfers' destination updates, each update's destination the destination signal's payload object and its value the shared fire identity equal to the matching source-ready equation's value. The invalid return is the owner's rejection path only (no rollback contract). The t8-module section of tests/rtl_lower_test.c is its own green tests/contracts.json entry (make rtl-lower-test T=t8-module), so every landing gate re-runs it. Its regression stance matches the fire-identity one — Option B, a permanent green manifest entry rather than a hidden packet (which would run only when re-merged into a candidate and split the contract across two places): the update-value/equation-value half of the module-composition contract is enforced by extending that same green t8-module section, asserting each update's value node is the shared non-constant fire identity equal to its matching source-ready equation's value (both `->value.index` and the shared-node property), so one manifest entry carries the whole gate contract and every landing gate re-runs it. This value assertion is not yet on master: the landed t8-module section asserts each update's destination object (up->destination.index) but not its value, nor the equation's value, so a value not shared with the matching source-ready equation (the lowered RHS, a fresh constant, or the INTEGER "valid 1" constant) currently passes undetected; the shared fire identity is non-degenerate (fire_bits_one, a 1-bit BITS literal), so the assertion is not vacuously true.

Remaining gate families — join, repeated projection, static-only assignment, process order, and the guard-and-dependency witness — are separate sections of the same file, each its own `make rtl-lower-test T=<section>` command, each red until its lowering lands and each absent from the file until its test packet lands; the rtl-lower-test manifest carries one entry per present section, so every manifest command passes on master.

Shared fire-identity probe helper. The fire-identity, join, and guard-and-dependency sections each assert that two lowered RTL expression trees share one memoized non-constant node via a single file-local helper (tests/rtl_lower_test.c): it collects every reachable expression identity from each root (identity-based, through the model's child links) and reports whether any shared identity is not a PIGEN_RTL_EXPR_INTEGER constant, so two trees sharing only a lowered constant do not satisfy the contract. The helper is re-established with the fire-identity section and must be present before the join and guard-and-dependency family sections are added, since those sections call it rather than inlining the tree walk.

Entry contracts. `pigen_lower_rtl_transfers(lowering, module)` returns 0/-1; it lowers the canonical guard atoms into the shared fire identity, the destination lvalue (static, projection or concatenation; buffered whole through their declaration endpoints), and the RHS through the expression memo with the assignment conversion above it. `pigen_lower_rtl_module` returns the composed module id (PIGEN_INVALID_ID on failure) via `pigen_rtl_module_add_with_owner`, `pigen_lower_rtl_module_declarations`, endpoint binding, processes, transfers, and the four published ranges.
