Transfers from one fire identity. Extend rtl_lower to combine the canonical guard, the distinct consumer-valid and producer-ready dependencies into one fire identity shared by destination updates and source-ready equations. Lower static lvalues/projections/concatenations, buffered destinations whole, and the assignment conversion above the RHS. One RTL process per semantic process. A failed call reports -1 and the compile stops; it may leave partial state behind, and no test asserts that a failure left the model or maps unchanged (how/should/compiler/builders/fail.md). Gate families: joins, repeated projections, static-only assignments, exclusive producers, process order. This is approved future work, not implemented status.

Entry contracts. `pigen_lower_rtl_transfers(pigen_rtl_lowering *, pigen_module_id)` returns 0/-1 and consumes the module's transfers: it lowers the canonical predicate atoms into one conjunction shared by the destination updates and the source-ready equations (the fire identity), lowers the destination lvalue (static, projection or concatenation; buffered destinations whole through their declaration endpoints), and lowers the RHS through the existing expression memo with the assignment conversion applied above it. `pigen_lower_rtl_module(pigen_rtl_lowering *, pigen_module_id)` returns the `pigen_rtl_module_id` of the composed module (PIGEN_INVALID_ID on failure): it calls `pigen_rtl_module_add_with_owner`, `pigen_lower_rtl_module_declarations`, endpoint binding, processes and transfers, and publishes the module's object/instance/equation/process ranges.

Verified owner API map (include/pigen/semantic.h, include/pigen/predicate.h, include/pigen/rtl.h). Transfers: `pigen_transfer_get` (module, process, destination lvalue, value, guard, domain, first_signal_use, signal_use_count, span); `pigen_transfer_signal_uses` returns the `pigen_transfer_signal_use` array (signal id + role bits PIGEN_TRANSFER_SIGNAL_READ/WRITE, PIGEN_TRANSFER_CONSUMER, PIGEN_TRANSFER_PRODUCER); `pigen_transfer_add` requires the process to belong to the module with the same clock domain, destination data type equal to the value data type, equal shapes, a valid guard, and duplicate-free signal uses. Predicates: `pigen_predicate_get` (first_atom, atom_count, impossible), `pigen_predicate_atoms`, `pigen_predicate_and_condition` (canonical conjunctive atoms {condition, expected}), `pigen_predicate_true/false`, `pigen_predicates_mutually_exclusive`. Lvalues: `pigen_lvalue_get` (kind PIGEN_LVALUE_PROJECTION/CONCATENATION, expression, data_type, span; projection carries base_symbol + signal; concatenation carries a sequence), `pigen_lvalue_children`. RTL owners: `pigen_rtl_module_add_with_owner`, `pigen_rtl_equation_add_with_owner`, `pigen_rtl_update_add_with_owner`, `pigen_rtl_process_add_with_owner` (clock expression, edge, update range), `pigen_rtl_module_get` (object/instance/equation/process ranges).

Owner-level gap the skeleton must close: the semantic model stores `processes` and `transfers` arenas, but exposes no owner getter enumerating a module's processes or a module/process's transfers; `pigen_process_get`/`pigen_transfer_get` validate a single id. The Task 8 skeleton establishes the smallest owner-level enumeration accessors (module -> processes; process -> transfers), not model-struct reach-through in the test or the lowering.
