Transfer realization adapter. Extend rtl_lower with declaration endpoints. Abstract boundary -> payload/valid/ready ports; combinational net/procedural variable -> constant controls; elastic slot/pulse/queue/skid -> corresponding primitive structure. Dispatch private adapter table by realization, not source transfer enum. Capacity/depth/ready/occupancy/reset come from descriptor. Gate: realization matrix and no PIGEN_TRANSFER_TYPE source-enum matches in rtl_lower.c; make transfer-type-test rtl-lower-test.

Data shapes. `pigen_rtl_signal_endpoints` holds payload (object id), valid/ready (expression ids), and input_payload/input_valid/input_ready (object ids); a constant control carries invalid object identity plus a constant-expression identity. `pigen_rtl_lowering` gains a signal-indexed `lowered_endpoints` map (keyed by pigen_signal_id.index, grow-on-demand like the two identity memo maps via `endpoint_map_ensure`); `pigen_rtl_lowering_init` zeroes it and `pigen_rtl_lowering_free` releases it. `pigen_lower_rtl_module_declarations(pigen_rtl_lowering *, pigen_module_id)` is the entry point with an int error contract. A private (static, file-local) `realization_endpoint_adapters` table in src/rtl_lower.c is indexed by pigen_transfer_realization with one entry per valid realization (BOUNDARY, COMBINATIONAL_NET, PROCEDURAL_VARIABLE, ELASTIC_SLOT, PULSE_REGISTER, PARAMETERIZED_QUEUE, SKID_QUEUE). Build seam: the `make rtl-lower-test` link line (Makefile:66) expands `$(SEMANTIC_SOURCES)` (Makefile:4) which includes src/transfer_type.c, so the Makefile link line is unchanged; src/transfer_type.c is in the rtl-lower-test `covers` entry in tests/contracts.json.

BOUNDARY owner constraints: the BOUNDARY realization is module-input only. PIGEN_TRANSFER_TYPE_ABSTRACT is the only source type mapping to it, its descriptor has is_concrete=0, and pigen_signal_add (src/semantic.c) rejects non-INPUT direction for non-concrete types and rejects a NULL transfer-type descriptor — so no OUTPUT-direction boundary signal and no NULL-descriptor/PIGEN_TRANSFER_REALIZATION_INVALID signal are constructible through the owner API, and no source descriptor maps to PIGEN_TRANSFER_REALIZATION_INVALID. The universal boundary handshake (what/is/an/abstract/input.md): payload and valid enter (inbound), ready leaves (outbound). ABSTRACT's descriptor carries valid_constant=-1 and ready_constant=-1 (context-dependent) and the BOUNDARY realization has ready_dependency PIGEN_TRANSFER_READY_EXTERNAL: a boundary signal has NO constant controls; valid and ready are context-dependent external controls, not owner-published 1-bit constants. Constant-expression-identity controls (invalid object identity plus constant-expression identity carrying the descriptor constant value) belong to the COMBINATIONAL_NET/PROCEDURAL_VARIABLE family (WIRE ready 0, REG ready 1, valid 1). The endpoints record's input_* object fields are the input-side exposure: for the INPUT direction they are the same three objects as payload/valid/ready.

Implementation contract. pigen_lower_rtl_module_declarations creates stable payload/valid/ready mappings; pigen_rtl_signal_endpoints stores the payload object ID, the valid and ready expression IDs, and the input_payload/input_valid/input_ready object IDs. A constant control has invalid object identity and a valid constant-expression identity. Obtain the source descriptor only to select the realization; use a private table indexed by pigen_transfer_realization and query capacity/ready/occupancy/reset there. The matrix maps boundary to three ports, net/variable to payload plus constants, and elastic/pulse/queue/skid to pigen_buf/pigen_port/pigen_fifo/pigen_skid. FIFO gets semantic depth. rg for PIGEN_TRANSFER_TYPE_(ABSTRACT|WIRE|REG|LOGIC|BUF|PORT|FIFO|SKID) in rtl_lower.c must have no matches. A failed call reports -1 and the compile stops; a failed call may leave partial state behind, and no test asserts that a failure left the model or maps unchanged (how/should/compiler/builders/fail.md).
