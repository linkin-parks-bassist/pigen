PIGEN_TRANSFER_TYPE_ABSTRACT is the only source type mapping to it, its descriptor has is_concrete=0, and pigen_signal_add (src/semantic.c) rejects non-INPUT direction for non-concrete types and rejects a NULL transfer-type descriptor — so no OUTPUT-direction boundary signal and no NULL-descriptor/PIGEN_TRANSFER_REALIZATION_INVALID signal are constructible through the owner API, and no source descriptor maps to PIGEN_TRANSFER_REALIZATION_INVALID. The universal boundary handshake (what/is/an/abstract/input.md): payload and valid enter (inbound), ready leaves (outbound). ABSTRACT's descriptor carries valid_constant=-1 and ready_constant=-1 (context-dependent) and the BOUNDARY realization has ready_dependency PIGEN_TRANSFER_READY_EXTERNAL: a boundary signal has NO constant controls; valid and ready are context-dependent external controls, not owner-published 1-bit constants. Constant-expression-identity controls (invalid object identity plus constant-expression identity carrying the descriptor constant value) belong to the COMBINATIONAL_NET/PROCEDURAL_VARIABLE family (WIRE ready 0, REG ready 1, valid 1). The endpoints record's input_* object fields are the input-side exposure: for the INPUT direction they are the same three objects as payload/valid/ready.

Implementation contract. pigen_lower_rtl_module_declarations creates stable payload/valid/ready mappings; pigen_rtl_signal_endpoints stores the payload object ID, the valid and ready expression IDs, and the input_payload/input_valid/input_ready object IDs. A constant control has invalid object identity and a valid constant-expression identity. Obtain the source descriptor only to select the realization; use a private table indexed by pigen_transfer_realization and query capacity/ready/occupancy/reset there. The matrix maps boundary to three ports, net/variable to payload plus constants, and elastic/pulse/queue/skid to pigen_buf/pigen_port/pigen_fifo/pigen_skid. FIFO gets semantic depth. rg for PIGEN_TRANSFER_TYPE_(ABSTRACT|WIRE|REG|LOGIC|BUF|PORT|FIFO|SKID) in rtl_lower.c must have no matches. The lowering snapshots the RTL model before publication and restores it exactly on a mid-sequence error, clearing only the call's own endpoint records, so a failed call leaves every arena and the previously populated endpoints unchanged.
