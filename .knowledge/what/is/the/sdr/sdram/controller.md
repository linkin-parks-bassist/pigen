cores/sdram/controller.pigen is a native single-word, closed-page SDR controller for x16 data, four banks, 8192 rows and 512 columns. Its 43-bit request is {write, byte_strobes[1:0], word_address[23:0], data[15:0]}; the address is {bank[1:0], row[12:0], column[8:0]}. Responses are {write, data[15:0]}, with zero acknowledgement data for writes. FSMs, when transfers and buffering own behavior; cores/sdram/pins.sv only maps DQ input/output/enable onto bidirectional pins. The system supplies the shared clock and keeps CKE high.

Assert synchronous reset at startup. Reset drops traffic and reinitializes the SDRAM; contents are unspecified across reset. Initialization waits INIT_CYCLES, precharges all banks, issues two refreshes, programs BL=1/CAS=2 or 3/single-write mode and waits MRD. Each access activates a row, waits RCD, accesses one word, allows read/write recovery and RAS, explicitly precharges and waits RP. READ data samples at the memory's READ+CAS edge, accounting for registered command outputs sampled on the next edge. A conservative access budget reserves refresh service before its deadline. Refresh continues while completed responses are stalled.

Cycle parameters are native int[32], matching the timers. Defaults INIT=20000, CAS=3, RP/RCD=2, RAS=5, WR=2, RFC=7, MRD=2 and interval=700 are exercised with a 10 ns simulation clock. Physical part, temperature grade, forwarded clock/phase, I/O cells and constraints require board qualification. Bursts, open-page optimization, self-refresh, power-down and electrical qualification remain outside this profile. The primary reference is the Micron MT48LC16M16A2 datasheet linked in tests/cores/run.py/results.json.

tests/cores/sdram_model.sv independently follows commands with full 24-bit-addressed storage, bank/row state, CAS-limited DQ drive, byte masks, initialization ordering, RP/RCD/RAS/WR/RFC/MRD/RC/RRD checks, refresh deadlines and runtime maximum active-row time. Reset restarts qualification while retaining bank state and in-flight pin reads. The first pre-reset pin sample is unqualified; reset asserts no data retention.

tests/cores/sdram_tb.sv checks 968 replies per profile, every address bit, bank/row/column boundaries, four byte masks, DQ contention, stalled output stability, a pending input blocked over multiple refresh intervals, and reset with stalled responses, an open row and a pin read in flight. Profiles cover default startup/CAS3, shorter functional initialization/CAS2 and stretched timings. Seven sdram_model_negative_tb sequences must fail for open-bank refresh, RP, RCD, RAS, WR, missed refresh and invalid mode; three invalid parameter configurations must fail at startup. Synthesizable sources pass warnings-fatal Verilator lint; Icarus runs the independent model/checkers. Report evidence includes native source, diagrams, initialization/read waveforms, comparisons, command CSVs, rejection logs and a read-timing movie.
