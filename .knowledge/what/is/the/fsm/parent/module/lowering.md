(s1) the structured FSM syntax node — COMPLETE. include/pigen/syntax.h carries PIGEN_SYNTAX_FSM (as.fsm: name, clock and reset as expression ids, initial token), PIGEN_SYNTAX_FSM_STATE (as.fsm_state.name) and PIGEN_SYNTAX_GOTO (as.goto_statement.target). src/syntax.c parse_fsm parses one module-level fsm item (the how/to/write/fsm/states.md grammar) into structured nodes with original spans, dispatched from parse_module_items; state bodies use the structured statement forms plus `goto IDENTIFIER`, which parses only inside an FSM body. Exactly one posedge clock edge, one reset signal, unique state names, and the initial state and every goto target must be declared states. A state-body statement outside the accepted ordinary forms (begin/end, if, pipeline, goto, nonblocking assignment) — a blocking assignment, a non-ordinary if/else body, or an empty statement — is rejected fail-loud with "fsm state body statement must be an ordinary statement" at the offending statement's original span.
