(s1) the structured FSM syntax node — COMPLETE. include/pigen/syntax.h carries PIGEN_SYNTAX_FSM (as.fsm: name, clock and reset as expression ids, initial token), PIGEN_SYNTAX_FSM_STATE (as.fsm_state.name) and PIGEN_SYNTAX_GOTO (as.goto_statement.target). src/syntax.c parse_fsm parses one module-level fsm item (the how/to/write/fsm/states.md grammar) into structured nodes with original spans, dispatched from parse_module_items; state bodies use the structured statement forms plus `goto IDENTIFIER`, which parses only inside an FSM body. Exactly one posedge clock edge, one reset signal, unique state names, and the initial state and every goto target must be declared states (a goto may forward-reference a later state). A failed parse reports the diagnostic at the original span and returns 0. The quarantined textual prototype's fsm.c/fsm.h (pigen_lower_fsms) is a different owner, untouched.

(s2) the FSM identity owner (include/pigen/fsm_identity.h + src/fsm_identity.c) — owner seam established as an interface-only skeleton. pigen_fsm_identity carries the FSM state type id, the one initial-state identity, the per-state identity set, the per-transition target set, the FSM original span and its owning PIGEN_SYNTAX_FSM node id; pigen_fsm_identity_establish fills it, pigen_fsm_identity_is_invalid pins it. SKELETON: establish validates its arguments and returns -1 leaving *identity invalid (PIGEN_INVALID_ID in every id, zero counts, empty span); the is_invalid predicate is real. A failed call returns -1 and the compile stops; it may leave partial state (how/should/compiler/builders/fail.md). The fsm-identity-test packet is preserved for the following test-contract item, per the (s1) precedent.
