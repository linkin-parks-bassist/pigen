## Per-line check (setup / action / observable result / seam reachability / discriminating mutation)

1. Reset value equals the header initial state's encoding: the non-first witness (header names run, index 1) lowers to rc == 0 and the reset-path update's value is a PIGEN_RTL_EXPR_CONDITIONAL whose when-true child is a PIGEN_RTL_EXPR_INTEGER of the state type with value 1. Reachable: the reset update is the one whose origin span is the FSM node's span (src/fsm_lower.c publishes it with fsm->location.source_span; every goto update carries its goto node's span), which distinguishes it from the goto-to-run transition whose when-true encoding is also 1. Mutation probe: a reset to the always-first encoding 0 fails the value-1 pin — the non-first witness (precedent FSM_WITNESS_NONFIRST in tests/fsm_identity_test.c, applied per how/to/write/a/discriminating/resolution/witness.md) makes this discriminating; the existing FSM_WITNESS names initial idle (the first state) and would let an always-first reset pass, so the file-local variant is a genuine prerequisite. One job: the reset-value assertion over one non-first fixture.
2. State-active gating on the action body: the run state (index 1) carrying the multi-statement body lowers to rc == 0 and the action equation (destination the owned object bound by provenance to the done output) has a CONDITIONAL value whose condition is a PIGEN_RTL_EXPR_BINARY PIGEN_BINARY_EQUAL comparison of the register read (PIGEN_RTL_EXPR_OBJECT) against a PIGEN_RTL_EXPR_INTEGER of value 1. Reachable: the implementation publishes exactly this structure (state_active_gate: pigen_rtl_expr_add_binary with PIGEN_BINARY_EQUAL over register_read and the state encoding, wrapped by gated_value); the comparison's operand structure (a register read compared to the state's encoding) is the pin a constant-gate or ungated action cannot fake, and it is unique among the published BINARY expressions (the other BINARY candidates — the state-encodings comparison family — key off different state encodings). Mutation probe: an ungated bare-constant action value is not a CONDITIONAL and fails; a constant-1 gate is not the register-read/encoding comparison and fails. One job: the state-active-gate assertion over the existing FSM_WITNESS.
3. Per-goto guard gating of the next state: the idle state's if (start) goto run; (target index 1) lowers to rc == 0 and that goto's update (origin the goto node's span, located through the parse) has a CONDITIONAL value with when-true the target encoding INTEGER 1 and when-false the register read. Reachable: src/fsm_lower.c publishes guard ? target : register_read per goto with the goto node's span as origin; the origin-span location is the discriminator (never a source-text search), and the when-false register read is the state-holds fact. Mutation probe: an ungated bare target encoding is not a CONDITIONAL with a register-read when-false branch and fails. One job: the guard-gating assertion for one located goto.
4. No transition ever waits for a transfer: the run state's if (!start) goto idle; (target index 0) lowers to rc == 0 and that goto's update value is the same (target-encoding, register-read) conditional shape over the explicit enclosing guard alone. Reachable as line 3 for the second transition; the mirror target (0 vs 1) keeps the line independent of line 3's fixture state. Mutation probe: a next-state keyed on a handshake/transfer condition instead of the guard changes the conditional's condition child away from the guard and fails. One job: the mirror-transition assertion.
5. One synchronous controller, one reset path: a legal two-state FSM lowers to rc == 0 and the parent module record owns EXACTLY ONE PIGEN_RTL_PROCESS (clocked posedge) whose update range holds exactly goto_count + 1 updates, all driving the single shared state register. Reachable: the implementation publishes one pigen_rtl_process_add_with_owner (PIGEN_SEMANTIC_POSEDGE) carrying the goto updates plus the single reset-path update; the exact count is the seam's pin of the one-controller structure and is what makes line 1's reset value part of the synchronous controller rather than a loose record. Mutation probe: a second process, a second reset update or a dropped reset update changes the count or the process's update range and fails. One job: the one-process/exact-count assertion.

## Coverage assessment

The list collectively pins the three behavior/stop obligations at the lowering seam where the (s4) anchors stop: line 1 pins the reset VALUE (the header-named state's encoding, token-text resolved, witnessed non-first so an always-first reset cannot pass); lines 2 and 3 pin the state-active gate and the per-goto guard gate as published record structure (the conditionals' operand shapes); line 4 pins the goto law's negative half (no implicit transfer wait) on the second transition; line 5 pins the one-synchronous-controller structure that makes the reset path part of the controller. Every named mutation (drop the reset value, drop the state-active gating, drop the per-goto guard gating, substitute an implicit transfer wait, split the controller) fails at least one line, so the list discriminates the current set-level-only manifest. Boundaries hold: the production/CLI emitted-SV contract (plan item 5) and the pipeline stage-computation/halting obligations (plan items 1 and 8) are named out of scope and no line pins them; the set-level record contract, the seam-red node-kind rejection and the four parse-level reds remain pinned by the (s4) manifest and are not re-mapped. The fixture prerequisites are minimal and established: one file-local non-first initial-state witness variant (precedent FSM_WITNESS_NONFIRST) for line 1, and reuse of the existing FSM_WITNESS for lines 2-4 and 5's count.

## Reviewed list (the five accepted scenario lines)

1. Reset value equals the header initial state's encoding: a legal two-state FSM whose declared states are idle then run and whose header names the NON-FIRST state as initial (initial run, per-state index 1) lowers to rc == 0, and the controller's synchronous process carries one reset-path update driving the state register whose value is a PIGEN_RTL_EXPR_CONDITIONAL whose when-true child is a PIGEN_RTL_EXPR_INTEGER of the state type with value 1 — the header-named state's index, not the first declared state's (an initial idle-style lowering that always resets to encoding 0 fails this line). Standalone pin: the reset update is the one whose origin span is the FSM node's span (every goto update's origin is its goto node's span, located through the parse), which distinguishes it from the goto-to-run transition whose when-true encoding is also 1; fixture prerequisite: a file-local non-first initial-state witness variant.
2. State-active gating on the action body: a legal two-state FSM whose run state (per-state index 1) carries the multi-statement body (done <= 1; then a guarded goto idle) lowers to rc == 0, and the action equation (destination the owned object bound by provenance to the module's done output) has a value that is a PIGEN_RTL_EXPR_CONDITIONAL whose condition is a PIGEN_RTL_EXPR_BINARY equal-comparison (PIGEN_BINARY_EQUAL) whose operands are the state register read (a PIGEN_RTL_EXPR_OBJECT naming the synthetic register) and a PIGEN_RTL_EXPR_INTEGER of the state type with value 1 — the action runs only while the run state is active (a lowering that publishes the action value ungated, as a bare constant, fails this line). Standalone pin: the state-active comparison is the only published BINARY expression whose right operand is an INTEGER of value 1, while every state encoding constant (one per declared state, values 0 and 1) is also published — the pin is the BINARY comparison's operand structure (register read compared to the state's encoding), which a constant-gate or ungated action cannot fake.
3. Per-goto guard gating of the next state: a legal two-state FSM whose idle state carries if (start) goto run; (target per-state index 1) lowers to rc == 0, and the update for that goto (origin the goto node's span, located through the parse) has a value that is a PIGEN_RTL_EXPR_CONDITIONAL whose when-true child is a PIGEN_RTL_EXPR_INTEGER of the state type with value 1 and whose when-false child is a PIGEN_RTL_EXPR_OBJECT naming the state register — the goto changes state only under its guard and the state holds otherwise (a lowering that publishes the transition ungated, as a bare target encoding, fails this line). Standalone pin: the per-goto origin span is the discriminator (each goto's update is located through its node's span, never a source-text search), and the when-false register read is the hold fact.
4. No transition ever waits for a transfer: a legal two-state FSM whose run state carries if (!start) goto idle; (target per-state index 0) lowers to rc == 0, and that goto's update value (origin the goto node's span) is a PIGEN_RTL_EXPR_CONDITIONAL whose when-true child is a PIGEN_RTL_EXPR_INTEGER of the state type with value 0 and whose when-false child is a PIGEN_RTL_EXPR_OBJECT naming the state register — the transition is keyed on the explicit enclosing guard alone, never on a handshake or transfer condition (a lowering that substitutes an implicit transfer wait for the guard fails this line). Standalone pin: the per-goto origin span plus the (target-encoding, register-read) conditional shape, mirroring line 3 for the second transition of the controller.
5. One synchronous controller, one reset path: a legal two-state FSM lowers to rc == 0, and the parent module record owns EXACTLY ONE PIGEN_RTL_PROCESS (clocked posedge, the synchronous controller of what/is/an/fsm.md) whose update range contains exactly goto_count + 1 updates — one per goto plus the single reset-path update — all driving the single shared state register (a lowering that splits the controller across two processes, publishes a second reset path, or drops the reset update from the process fails this line; this count is the seam's exact pin of the one-controller structure, and the reset path's presence in the process is what makes the reset value of line 1 part of the synchronous controller rather than a loose record).
