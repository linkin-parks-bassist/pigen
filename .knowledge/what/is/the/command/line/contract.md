The `pigen` CLI compiles one `.pigen` source through the structured pipeline (preprocess, lex, parse, semantic, RTL lowering, naming, output model, SV emission) via `pigen_compile_source`. Contract: silent success — the output file is written, stdout is empty, exit 0, no "wrote" notice; loud failure — a diagnostic goes to stderr, the exit code is nonzero, and no output file is written (no partial output). Diagnostic form (report_error in src/pigen.c, pinned by tests/cli_diagnostics_test.sh): a compile error carrying a valid non-degenerate source span prints three stderr lines — `<input-path>:<line>:<column>: <message>`, the offending source line prefixed with exactly 4 spaces, then 4 spaces, (column-1) spaces and a single caret — with the line/column resolved from the span through the source manager built from the input file; a spanless stage failure (or missing/invalid span) prints the single line `pigen: <message>`, falling back to `pigen: compile failed` when the message is NULL. Arguments: `pigen INPUT.pigen [-o OUTPUT.sv]`; without `-o` the output path is the input path with `.sv` substituted (a `.pigen` suffix becomes `.sv`) or appended (otherwise `.sv` is appended to the full path). This no-`-o` success-path derivation is the one CLI-contract obligation the accepted diagnostics contract does not pin: that contract's success case passes an explicit `-o`, and its no-`-o` cases fail before any output file is written, so a wrong derivation would still pass the suite. Argument errors print usage to stderr and exit 2. The structured frontend accepts the data-first declaration dialect (data type, then optional transfer annotation, then name, e.g. `logic [7:0] buf stage;`); transfer-first prototype spellings such as `buf [7:0] stage;` or `input buf [7:0] request` are diagnosed at the original span by design, not accepted — the existing tests/examples corpus is written in the prototype dialect and is migrated per subsystem (what/are/the/remaining/architecture/migration/gates.md). No validator bridge, fallback, second dialect or per-file choice.
