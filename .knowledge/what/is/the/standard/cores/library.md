The native library under cores/ provides UART TX/RX with 5–9 data bits, none/even/odd parity and one/two stop bits; eight-bit SPI controller and oversampled target in all four modes; an open-drain I2C controller byte engine and seven-bit addressed target; continuous-clock 16-bit-stereo I2S full duplex; 32-bit AXI-Stream FIFO with TKEEP/TLAST; four-word AXI4-Lite registers; x16 SDR SDRAM; and a 32-bit/four-ID-bit AXI4 burst-to-native-memory bridge. Data-first types, always processes, anonymous FSMs, ordinary reset/goto and when events implement logic. AXI cores declare native protocol endpoints and emit standard pins directly. SDRAM retains its bidirectional DQ adapter.

`make cores-test` runs 122 cases with independent pin/scoreboard tests and warnings-fatal lint. UART covers all 30 framing formats at divisors 4 and 7, exhausts each payload space, and retains five default-8N1 divisor cases; tests include parity corruption, every stop position, back-to-back reception, false starts, full-output errors, break and reset recovery. SPI controller tests four modes/three periods; its target adds 12 asynchronous timing/mode profiles, exhaustive bytes, streaming CS, late TX, hold timing, underrun/overrun and abort/reset (what/is/the/spi/target/core.md). I2C controller tests three periods, ACK/NACK, repeated START, chaining and stretching. Nine I2C target profiles exhaust addresses/bytes, ACK/NACK, backpressure, queued-byte preservation and partial abort/reset (what/is/the/i2c/target/core.md). I2S tests 40 frames at three periods, WS lead and silence/drop. AXI-Stream checks sidebands, ordering, five-beat capacity and stalls/reset. AXI4-Lite uses three independent-channel/strobe/stall seeds. SDRAM checks three CAS/timing profiles with 968 replies each, full addressing, byte masks, initialization and refresh. AXI4 uses three seeds with 1069 replies each, independently checked backend requests, FIXED/INCR/WRAP, 256 beats, narrow/unaligned traffic, IDs/errors/stalls/reset.

Seven compiler regressions cover child-output concatenations, unary intrinsics, retained parameters, combinational observations, 65536 integer-resize patterns and 8192 concatenation-resize byte checks. The when-value regression checks 1536 independently stalled ternary/logical/relational results and fatal malformed-header diagnostics. The explicit fork/join example checks six ordered 3N+1 results. Twenty-six invalid parameter configurations fail at startup; seven malformed SDRAM sequences prove checker rejection. Waits are bounded.

Profiles remain explicit. UART drops newest RX on a full output and rejects bad parity/framing; SPI controller selects one target per byte; oversampled targets need qualified input timing. I2C omits arbitration/timeout and its target omits reserved/general-call/ten-bit/filter support. I2S inserts silence/drops newest on underrun/overrun. AXI-Stream omits routing/user sidebands. AXI4-Lite ignores protection. SDRAM uses closed-page single words, without bursts/self-refresh. AXI4 serializes each backend direction and omits exclusive/USER/out-of-order handling. Shared resets discard traffic.

`make cores-report` builds source panels, twelve interactive players with 33 native internal subsystem views, diagrams, waveforms, comparisons and an evidence ZIP. Native data dependencies, ordinary continuous assignments, observed registers and state strips appear with uniform clocks and endpoint colours; reset cases and invented mux/decode hardware are omitted. Every internal view has a rendered layout check; intrinsic FIFO internals stay opaque. Observed write results are checked against next register states. `make cores-video` adds ten movies. Procedures and visual acceptance belong in how/to/create/standard/core/test/artifacts.md and how/are/pigen/transfer/types/displayed/in/test/artifacts.md.

Broader profiles and hardware qualification remain future work; SDRAM part/temperature/clock and FPGA I/O timing need selection and qualification. Simulation proves exercised behavior, not physical timing or full formal compliance.
