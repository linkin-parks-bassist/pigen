`pigen_emit_systemverilog` renders one finished, named RTL lowering to a single SystemVerilog text. It is the structured path's terminal emitter (what/is/elastic/rtl/task/order.md), consuming only already-resolved records; it never re-derives meaning.

Signature and ownership: `int pigen_emit_systemverilog(const pigen_source_manager *sources, const pigen_output_model *layout, const pigen_rtl_model *rtl, char **output_string);`. `sources` owns the opaque span text; `layout` is the ordered output model from `pigen_build_output_model`; `rtl` is the finished RTL model whose `names` arena is populated by `pigen_rtl_assign_names`; `output_string` is an out-param. Returns 0 on success with `*output_string` a newly-allocated, NUL-terminated string the caller frees, or -1 on any failure leaving `*output_string` NULL and no partial output (how/should/compiler/builders/fail.md): it validates first, renders into a private buffer, and commits `*output_string` only on success.

Emission rule: walk `layout` items in array order (a MODULE item's nested range is the owner-managed layout of its children, rendered inside the module) into one private growable buffer. Per item kind:
- OPAQUE: copy its span's text verbatim from `sources` via `pigen_source_span_text` (no re-parse, no trim).
- MODULE: emit the module header and close `endmodule`; its nested items render inside, in their own order.
- RTL_OBJECT / RTL_INSTANCE / RTL_EQUATION / RTL_PROCESS: render from the matching RTL record and its final name.

Whole-design layout (byte-exact): top-level items emit in array order, each line newline-terminated; the text ends with the last line's newline. A module renders `module <name> (`, then its nested items in nested order, then `);` (immediately after `module <name>` when it has no ports), then `endmodule`. Port objects (direction INPUT/OUTPUT) render as header lines `  input  logic [h:l] <name>,` / `  output logic [h:l] <name>,` — direction keyword right-aligned to six columns, `logic` present only when width != 1, `[h:l]` the type's first packed dimension range, comma on every port but the last; internal objects render `  logic [h:l] <name>;` (`  logic <name>;` at width 1). An instance renders `  <name> #(.P(v),...) (.p(o),...);` with each side present only when its range is non-empty (a literal parameter renders its value). An equation renders `  assign <dest> = <value>;`. A process renders `  always @(<edge> <clock>)`, then each update as `    <dest> <= <value>;` (four-space indent).

Names: a record's final name is the `pigen_rtl_name` in `rtl->names` whose identity (role kind + origin span, per `same_identity`) matches the record's role and origin; render `name->text` directly. An object matches a SOURCE-kind name on its origin span; a module matches a SOURCE-kind name on its own identifier span (distinct from the module record's origin span); an instance with an invalid origin matches its synthetic INSTANCE-kind name (the role stem, e.g. `instance`). No generated text is ever re-searched or re-interpreted.

Expression rendering: recursive descent over `pigen_rtl_expr` kind, one fixed precedence level per kind, structurally necessary parentheses, and one private operator-rendering table. Kinds: INTEGER/BITS (literals), OBJECT (a name), UNARY/BINARY (operator from `as.unary.resolution`/`as.binary.resolution`), CONDITIONAL (`? :`), CONVERSION, INDEX (`[idx]`), SELECT (a range or indexed-up select renders `[left:right]`, indexed-down `[left]`, per `as.select.kind`), CONCATENATION (`{a,b,...}` over children). CONVERSION renders from the RTL operand and target type only: `PIGEN_CONVERSION_INTEGER_RESIZE` applies the target's signedness cast directly on the operand with no width prefix (`signed'(<operand>)` / `unsigned'(<operand>)`); every other kind renders the target's full cast `signed'(<width>'(<operand>))` / `unsigned'(<width>'(<operand>))`, which is valid SystemVerilog preserving both width and signedness (a conversion result carries its target type, so the emitted form must establish that width). The malformed leading-apostrophe spelling `'signed'(a)` is invalid SystemVerilog (a Verilator syntax error, `unexpected "'"`) and dropped the width; the t10-golden golden was corrected to the full cast `signed'(16'(a))` for its 16-bit SIGNED REINTERPRET of the 8-bit OBJECT operand `a`. The protected t10-expr-render section pins the RESIZE case (`signed'(1)`); the corrected t10-golden packet pins the non-RESIZE full cast, so both conversion forms are now fixed by a green test. Child order is `first_child`/`child_count` via `pigen_rtl_expr_children`. Tests reach the renderer through the public seam `int pigen_sv_render_expression(const pigen_rtl_model *rtl, const pigen_rtl_expr *expr, char **text);` in `include/pigen/sv_emit.h`: a thin package-internal wrapper over the file-local renderer, returning 0 with a newly-allocated, NUL-terminated text the caller frees, or -1 leaving `*text` NULL with no partial output. The public surface is only `pigen_emit_systemverilog` and this test seam.

Types: widths, signedness and packed dimensions come from `pigen_rtl_type` (`signedness`, `state_domain`, `width`, `dimensions`, `dimension_count`) only. The emitter never consults a semantic symbol, data type, or transfer type.

Structural boundary (enforced, not a comment): `sv_emit.c` contains no source-text search or semantic-owner lookup. A structural grep for `strstr`, `strchr`, `pigen_symbol_lookup`, `pigen_data_type_`, and `pigen_transfer_type_` must return no matches; the only text reads are `pigen_source_span_text` (opaque spans) and `pigen_rtl_name_get` (final names).

Build seam: `make sv-emit-test` compiles `tests/sv_emit_test.c` with `src/sv_emit.c` plus the minimal record owners (`src/rtl.c`, `src/source.c`, `src/rtl_name.c`, `src/util.c`) and runs `/tmp/pigen-sv-emit-test $(T)`; each section is its own `tests/contracts.json` entry (`make sv-emit-test T=t10-<section>`). The gate is `make sv-emit-test`, `make output-model-test` and `make rtl-test` green.
