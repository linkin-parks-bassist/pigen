pigen_emit_systemverilog renders finished named RTL and output layout without semantic-symbol or transfer-type lookup.

Signature: `int pigen_emit_systemverilog(const pigen_source_manager *sources, const pigen_output_model *layout, const pigen_rtl_model *rtl, char **output_string);`. Sources own retained text; layout orders RTL-owned hardware/names. Success returns 0 and allocated NUL-terminated output. Failure returns -1 with output NULL and no partial text. Validation precedes private-buffer rendering. Empty designs yield allocated empty strings; NULL output validates/discards rendering.

Layout orders records. PARAMETER localparams and initialized variables use declaration assignments (how/are/static/procedural/initializers/represented.md). Modules render ports, declarations, items and endmodule. OPAQUE copies source bytes; RETAINED uses prepared text or source at every scope. Other items render RTL records.

Declarations use resolved RTL types or model-owned declaration_type for static packed records (how/are/static/packed/record/declarations/emitted.md), followed by final names and unpacked shapes. Two-/four-state types use bit/logic; native integer keywords remain native. Ports support input/output/inout. Packed dimensions preserve recorded left/right bounds, including ascending, nonzero and multidimensional coordinates, as values or expressions. Only dimensionless vectors fall back to [width-1:0]. One-bit [0:0] emits scalar. Primitive PAYLOAD_T uses the same renderer. Dimensions never come from semantic lookup or reconstructed source.

Equations use destination_expression when present or the base destination. Clocked processes render clocks/edges/guards/updates; combinational processes render validated ordered blocks, if/else, case/casez/casex, loops with lexical exits and blocking assignments (how/are/scoped/combinational/processes/represented.md). Primitive instances use enum/payload/parameters/connections; generic instances own definition/name/directional connections. OUTPUT/INOUT expressions render writable paths (what/is/the/terminal/systemverilog/emitter/instance/primitive/ownership.md). Names come from RTL identity/origin; generated text is never searched to recover meaning.

Expressions render recursively with precedence and parentheses. Nested unary operands are parenthesized to prevent token merging. FOUR_TO_TWO clears unknowns with bounded native integer-cast chunks (how/are/four-state/values/converted/to/two-state/types.md). Every conversion carries target width and signedness, e.g. signed'(64'(a)). A sign-only cast does not resize. render_at_width preserves a composite child's intrinsic width before a surrounding resize. Binary emission uses recorded result/operand widths to make required working-width padding explicit, while shift/power count operands retain their own widths. This preserves carries, narrowing and nesting without context-driven width warnings. Signed typed member-select values render a signed cast; destination paths stay writable and coordinate expressions retain value context. Emission performs no semantic inference. Native AXI standard pins and pack/unpack equations arrive as finished RTL records from rtl_lower.c; the terminal renderer has no AXI-specific source interpretation.

Literal rendering inspects every word. High data bits or X/Z masks select sized binary output preserving all states; otherwise decimal output suffices. BITS carries resolved width and an explicit signed marker when signed; INTEGER retains host-word decimal magnitude and negative sign. Multiword binary rendering uses resolved width and zero-fills absent upper bits. SELECT renders prepared member_name as `.field` (how/are/ordinary/packed/record/sub-projections/lowered.md), or [:], [+:] and [-:] for ranges. Children come from RTL expression ranges.

include/pigen/sv_emit.h exposes pigen_sv_render_expression, returning allocated text or NULL. Structural boundaries forbid source-text searches and semantic APIs in sv_emit.c; retained spans/final-name reads are allowed.
