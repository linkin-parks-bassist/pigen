The native model is one typed AXI endpoint with typed channel projections, implementing the requirements in what/are/the/native/axi/transfer/requirements.md. Declarations, named configuration, channels/fields, channel storage and standard pins are implemented; source syntax remains revisable. Acceptance remains scoped to verified profiles. Source details: how/to/write/native/axi/declarations.md.

An endpoint describes protocol family, role, address/data/ID widths and applicable optional fields. AXI4-Stream has one forward beat channel; AXI4-Lite and AXI4 have AW, W, B, AR and R channels, with B/R flowing opposite AW/W/AR. Channel projections expose named payload fields and native Pigen transfer operations; each channel has its own fire event. Endpoint role determines channel direction, so one memory-mapped endpoint cannot be described honestly as a single unidirectional input token.

A whole-endpoint child connection resolves semantic endpoint identities, checks complementary roles and complete protocol compatibility, and lowers every selected channel and sideband with the correct direction. Full AXI4 and AXI4-Lite remain distinct contracts. Protocol conversion, width conversion and optional-field adaptation require defined behavior; generic payload compatibility must not silently authorize them.

Protocol and storage need distinct representations within the transfer model. An AXI channel may need buffering, while its AXI identity remains unchanged. Existing buf/fifo/skid laws can serve channel storage where their behavior satisfies the protocol. Adding an enum whose realization is just buf would leave multi-channel direction, sidebands and compatibility unrepresented. The endpoint contract belongs in semantic types; pin spelling and flattening belong in RTL boundary lowering before terminal emission.

Source-side channel realization must hold VALID and the complete beat stable until acceptance and avoid waiting for READY before offering VALID. Independent AW/W acceptance, response backpressure, reset behavior, burst length/last/ID rules and ordering need explicit laws and independent RTL witnesses. The complete five-channel endpoint has no single valid/ready/fire value. Ordinary channel-level atomic composition does not by itself enforce legal AXI transaction sequencing; endpoint behavior must own those obligations.

Whole-endpoint named and positional child bindings use canonical semantic endpoint views, standard-pin mappings and translated clock/reset identities. Child projections and forward sibling connections work without pack/unpack adapters. Independent stalled hierarchy simulations cover all families and negative contract/role/timing/ownership cases. The standard Stream FIFO, Lite register bank and full AXI bridge use native endpoints and named response records; independent standard-pin transaction scoreboards pass. Full AXI4 acceptance must name the implemented profile and verify applicable burst/ID/ordering behavior.

Memory-mapped and Stream fabrics have distinct semantics. A separate memory-mapped spelling remains open; both currently use fabric syntax. Typed standalone fabrics and whole-bus links accept native parent ports and child endpoints (how/to/write/typed/standalone/fabrics.md); Stream arbitration policy: how/are/native/stream/fabric/identities/preserved.md. how/are/native/axi/fabrics/connected/and/arbitrated.md owns the implemented memory-mapped ownership profile, verified source-ID tagging/exclusive monitor identity and remaining richer routing. Named channel records and explicit defaults are implemented in assignment contexts (how/to/construct/typed/records.md). Open work includes remaining expression-pattern contexts, remaining projection contexts/conversions, provisional extern-module contract verification (how/are/native/axi/endpoints/mapped/to/external/systemverilog/ip.md), transaction conveniences and richer fabric topologies. Boundary isolation and reset/clock laws must satisfy AXI interface requirements. These should be resolved with concrete source examples before freezing a public interface.

Compiler evidence for ordinary channel storage: include/pigen/transfer_type.h, src/transfer_type.c and cores/axis, cores/axil, cores/axi4.
