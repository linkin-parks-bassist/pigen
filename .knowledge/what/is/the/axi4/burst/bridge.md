cores/axi4/bridge.pigen implements a native AXI4-to-memory-request bridge with 32-bit data/byte addresses and four-bit IDs. The pigen_axi4_bridge module declares a native axi4[addr=32,id=4] s_axi endpoint and emits standard pins directly; pins.sv is a comment-only compatibility placeholder. Independent read/write FSMs service one active burst each with elastic boundaries; no out-of-order completion occurs. A native W buffer accepts an early beat independently of AW.

Supported transfers are FIXED (up to 16 beats), INCR (up to 256), and aligned WRAP lengths 2/4/8/16, with byte/halfword/word sizes. FIXED/INCR starts may be unaligned. INCR aligns subsequent beats to transfer size. WRAP progresses within its power-of-two region. WSTRB is checked against eligible lanes, including the shortened first unaligned transfer. Native backends receive word-aligned addresses and full bus-lane data. Reads return the backend's full word; the AXI transfer size determines relevant lanes. IDs, RLAST, per-beat read status and aggregated write status are preserved under stalls.

Captured internal address state: Ax is {lock,burst[1:0],size[2:0],len[7:0],id[3:0],address[31:0]}; W is {last,strobes[3:0],data[31:0]}; B is {id,resp}; R is {last,id,resp,data}. B/R are constructed as named typed records on the native endpoint. The 68-bit write request is {strobes,address,data}, with a two-bit reply. Read requests are 32-bit aligned addresses with 34-bit {resp,data} replies. Each backend direction completes one request at a time and returns one ordered OKAY/SLVERR/DECERR reply per accepted request. Both interfaces share synchronous reset; the backend must flush outstanding work/replies on reset.

Invalid descriptors (size, burst encoding/length/alignment, INCR 4 KiB crossing or address overflow) return DECERR without backend requests. Writes drain AWLEN+1 beats even on errors. Invalid lane strobes suppress that beat's backend write and add SLVERR; malformed WLAST adds SLVERR without changing the AWLEN drain length. Zero strobes are no-ops. Backend error status accumulates by severity. Cache/protection/QoS/region attributes are ignored. No exclusive monitor exists: AxLOCK is ignored and successful accesses respond ordinary OKAY, following Arm IHI0022E A7.2.3/A7.2.5. USER sidebands are absent.

tests/cores/axi4_tb.sv independently computes address progression by division/modulo, eligible lanes byte-by-byte, expected backend requests and AXI responses. Three deterministic stall/latency seeds each check 1069 replies, all sizes/start offsets/IDs, WRAP lengths, 256-beat INCR, legal page-end unaligned access, 32-bit WRAP/overflow, backend errors, descriptor/WLAST/strobe errors, independent channels, response/backend stability and reset with stalled traffic or early W. The runner lints synthesizable RTL with warnings fatal and simulates Icarus evidence. The gallery exposes native source, separate read/write diagrams, pin waveforms, comparisons, backend.csv, VCD/logs and an actual trace timing video.
