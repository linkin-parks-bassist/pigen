The whole-design golden (what/is/the/terminal/systemverilog/emitter/contract.md) originally rendered an instance as `  instance #(.DEPTH(8)) fifo (.clk(clk));`: the instance's final NAME is the synthetic role stem `instance`, but the line also showed the instantiated primitive's definition name (`fifo`) and each parameter's name (`DEPTH`). Those two spellings are not ownable by the structured emitter, so the instance line was the one part of the golden a contract-consistent, no-hardcoding emitter could not render.

What the record owns (include/pigen/rtl.h, `pigen_rtl_instance`): `origin`, `semantic_module` (a `pigen_module_id`, provenance and invalid when the instance is synthetic), `parameters` (an ordered range of value expressions only — the depth literal 8, no parameter-name text), `connections` (object IDs), and `module` (invalid until a later owner-resolution stage publishes it). The final NAME `instance` comes from `pigen_rtl_assign_names` for an invalid-origin INSTANCE request (role stem, src/rtl_name.c).

What is missing: (1) no owner API resolves a `pigen_rtl_module_id` to a primitive definition name such as `pigen_fifo`; the prototype's `pigen_prototype_transfer_descriptor.primitive_module` and `pigen_primitive` are textual-path machinery the emitter's structural boundary (what/is/the/terminal/systemverilog/emitter/contract.md) forbids it from consulting. (2) no record carries a parameter-name spelling; `parameters` holds only value expressions. what/is/elastic/rtl/task/six.md section 13 states this explicitly: "there is no owner API resolving a pigen_rtl_module_id to a primitive definition name ... That mapping is a design decision the implementation fills."

Resolution (chosen, path A re-scope): the golden instance line is re-scoped to the representable form `  instance #(8) (.clk(clk));` (parameter VALUE 8 with no name; the instance name is the synthetic INSTANCE role stem; the connection port name clk). The alternative ownership route — establishing a primitive-definition-name and parameter-name spelling so the golden keeps `  instance #(.DEPTH(8)) fifo (.clk(clk));` — was NOT taken: main has no primitive/parameter name roles or ownership, and that gap remains open (a later owner must publish the spelling if the named form is ever required). Until then, `pigen_emit_systemverilog` emits the re-scoped form and must not hardcode `fifo`/`DEPTH` (the user forbids hardcoding and the structural boundary forbids consulting the textual-path machinery).
