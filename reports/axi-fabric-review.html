AXI fabrics: implementation
and verification

A review of the protocol-aware interconnect work preserved for a future architectural decision.

Current status: quarantined · not in use

Native AXI fabric links are disconnected from compiler semantic publication and RTL lowering. This includes AXI4-Stream, AXI4-Lite and full AXI4, for direct and routed whole-interface fabric connections.

Native AXI module ports, child bindings and explicit channel transfers remain active. Ordinary scalar fabrics and the balanced three-port routing tree remain active.

What was built

The retained AXI implementation uses protocol-aware switches and arbiters. It does not map AXI transactions onto the ordinary three-port source-routing tree. Memory-mapped interconnects maintain address selection and transaction ownership across independently handshaken request and response channels.

Limits that matter

  • Memory-mapped routing selects the whole burst from its starting address. It performs no address translation, burst splitting or malformed-transaction repair.
  • One outstanding write plus one independent read limits concurrency at each memory-mapped arbiter/decoder. This is a finite supported profile, rather than a general high-concurrency interconnect architecture.
  • Widths and sideband contracts must match, apart from the defined ID adaptation. Arbitrary data-width conversion and clock-domain crossing are not implemented by these fabric paths.
  • Reset is synchronous. Address windows are compile-time values, represented within 64 bits; source fan-out is bounded at 32 destinations.
  • An unmapped Stream destination stalls at the queue head. Memory-mapped decode misses return DECERR.
  • The real full-AXI bridge has no exclusive monitor. Exclusive identity was checked using separate synthetic monitor profiles.

How strong is the evidence?

The evidence consists of finite independent RTL simulations, compiler models, negative cases and fatal lint. It establishes the exercised profiles. It does not establish exhaustive protocol compliance, deadlock freedom for every composed network, device-specific area/timing, or equivalence to a mature configurable AXI interconnect.

The retained source baseline is 16832c043357043360da143094fec6391dd890fb. The earlier native gate was verified in phases; there was no single uninterrupted final invocation covering every native recipe. Passing core-fabric and contention runs are recorded in the project knowledge owners. The quarantine adds explicit rejection tests and preserves active boundary transport witnesses.
