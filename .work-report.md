## What exists now

`pigen_lower_rtl_transfers` in `src/rtl_lower.c` is implemented. The stub body
(reported -1 unconditionally) is replaced with the full first-pass transfer
lowering:

1. Validates `lowering` and `module` (NULL or invalid -> -1).
2. Calls `pigen_lower_rtl_module_declarations` to ensure all signal endpoints
   are published before any transfer work.
3. Resets the fire-identity memo (`fire_memo_reset`) for this call.
4. Resolves the RTL module via the file-local `rtl_module_for_semantic` helper.
5. For each semantic process in arena order (`pigen_module_processes`):
   - Lowers the process clock expression via `lower_expr`.
   - For each transfer in that process (`pigen_process_transfers`):
     - Computes the fire identity via `fire_identity_for_transfer`.
     - Resolves the destination lvalue (projection kind only; concatenation
       is a later pass).
     - Publishes the source-ready equation
       (`pigen_rtl_equation_add_with_owner`) with the fire identity as value.
     - Publishes the destination update
       (`pigen_rtl_update_add_with_owner`) with the fire identity as value.
   - Publishes one RTL process (`pigen_rtl_process_add_with_owner`) carrying
     the lowered clock, the domain edge, and exactly that process's update ids
     in arena order (empty process -> empty updates range, update_count 0).
6. Returns 0 on success.

## Build seam fix

The `rtl-lower-test` Makefile target was missing `src/predicate.c` in its link
list. The already-landed `fire_identity_for_transfer` helper calls
`pigen_predicate_get` and `pigen_predicate_atoms` (defined in `src/predicate.c`);
the previous stub suppressed the unused-function warning without creating a
call, so the linker never needed those symbols. Now that the entry point
actually calls the helper, `src/predicate.c` must be linked. Added it to the
`rtl-lower-test` target's source list.

## Boundary report

**Interface exposed:** `pigen_lower_rtl_transfers(lowering, module) -> int`
(0 success, -1 error). Publishes equations, updates, and processes into the
RTL model. Populates `lowering->lowered_endpoints` via the declaration call.

**Assumed of neighbors:**
- `pigen_lower_rtl_module_declarations` is idempotent and publishes all
  endpoint records before returning 0.
- `fire_identity_for_transfer` returns a valid lowered expression for any
  transfer whose endpoints are already published.
- `pigen_rtl_equation_add_with_owner`, `pigen_rtl_update_add_with_owner`,
  `pigen_rtl_process_add_with_owner` accept `update_count 0` for empty
  processes.

**Error/ownership rules:** No rollback; a failed call may leave partial state.
The compile stops on -1 (how/should/compiler/builders/fail.md).
